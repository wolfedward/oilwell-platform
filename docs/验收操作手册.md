# 油井数字智能化管理平台验收操作手册

## 一、现场准备

1. 使用 Windows 电脑，在项目根目录双击 `start-platform.cmd`。
2. 浏览器自动打开 `http://127.0.0.1:8765/`；地址必须是本机回环地址，拔掉外网后仍可运行。
3. 登录后先打开“系统管理 → 系统运行”，确认应用服务、业务数据库均为 `ok`，采集模拟器为 `running` 或 `ready`。
4. 如浏览器没有自动打开，手工在 Edge 或 Chrome 输入上述地址。不要重复双击启动；平台使用单实例锁避免两个进程同时写数据库。

## 二、岗位账号

| 岗位 | 用户名 | 密码 | 主要操作 |
| --- | --- | --- | --- |
| 系统管理员 | `administrator` | `Admin@2026` | 审批、审计、账号权限、全局查询 |
| 生产工程师 | `production_engineer` | `Production@2026` | 井况分析、策略优化、提交审批 |
| 算法工程师 | `algorithm_engineer` | `Algorithm@2026` | 电功图转换、示功图诊断 |
| 设备运维 | `maintenance_engineer` | `Maintenance@2026` | 终端配置、补传修复、指令下发与工单 |
| 业务复核员 | `reviewer` | `Review@2026` | 业务查询、报表与只读复核 |

账号按岗位最小权限分离；策略创建人不能代替管理员完成独立审批。

## 三、15—20 分钟主验收路径

### 1. 全场运行与单井追溯（2 分钟）

以管理员登录，打开“运行总览 → 综合看板”。检查生产、在线终端、数据质量、活动报警、策略与节能指标，点击指标进入明细。进入“油井管理 → 油井台账”，筛选低产井并打开一口井，确认生产历史、遥测、关联终端、最新功图、诊断、策略、报警和工单来自同一井号。

### 2. 数字采集与异常修复（3 分钟）

打开“采集监控 → 采集实况”，观察报文序号、终端时间、接收时间、摘要和状态；使用暂停/继续验证前端轮询不会制造数据。打开“数据质量”，查看序列缺失、延迟、漂移、重复、结构与校验事件。以设备运维账号对未修复的序列缺失执行“补传修复”，确认状态、修复详情与审计记录同步变化。

### 3. 电功图到示功图及智能诊断（4 分钟）

以算法工程师登录，进入“功图智能 → 功图档案”，打开一条功图并运行分析。分析页应同时展示原始电功图、滤波结果、转矩换算、示功图、模板相似度、特征参数、规则命中、候选工况、产液量公式因子及模型版本。进入“诊断复核”可查看机器结论；人工复核会另存记录，不覆盖机器输出。

### 4. 低产井节能控制闭环（6 分钟）

1. 生产工程师在“节能控制 → 渗流分析”查看恢复观测点、拟合曲线、时间常数、拟合优度和淘汰原因。
2. 进入策略编辑，检查启停时间、最低产液量、每日最大启动次数和电机功率约束，计算候选制度后保存并提交。
3. 管理员在“协同处置 → 审批中心”填写意见并批准。确认审批人不是策略创建人。
4. 设备运维在“策略中心”下发批准策略，在“指令中心”处理待执行指令。
5. 打开指令详情，检查 64 位摘要签名、幂等键、有效期、安全校验以及发送、接收、校验、执行、成功五阶段回执。
6. 返回策略详情确认状态为“生效”，并在节能报表中查看实测覆盖率、节电量与产量保持率。

### 5. 报警、工单、报表和审计（3 分钟）

在“报警中心”查看来源对象并执行合法状态动作；创建或打开关联工单，依次完成派发、处理、验证和独立关闭。进入“报表中心”导出 CSV。最后在“审计日志”按对象类型或操作过滤，核对登录、分析、审批、下发、工单和导出记录；审计页无删除入口。

### 6. 年度任务证据（2 分钟）

打开“验收中心 → 成果证据”，逐项进入六个能力项：示功图转换、可靠采集、信息传输、决策支持、节能控制和智能测控。该页只汇总数据库内可追溯的系统能力与业务记录，不代替著作权或专利申报材料。

## 四、验收前自动巡检

在项目目录打开 PowerShell，执行：

```powershell
python acceptance_smoke.py
```

退出码为 0 且输出 `status: passed` 才可继续。巡检使用隔离数据库，依次检查健康、四岗位登录、看板、单井、功图分析、优化审批、签名下发、五阶段回执、CSV、审计、年度证据及重启保持，并在 `logs` 目录生成时间戳 JSON 报告，不修改现场数据库。

## 五、结束操作

先双击 `backup-platform.cmd` 留存数据库，再双击 `stop-platform.cmd`。确认浏览器刷新后不再能访问服务；`logs/runtime.log` 中应出现 `stop completed` 和 `stopped`。
