# 工况模型软件验证（WP05B）

本模块是研究用途的纯计算程序：`train_conditions` 和 `predict_conditions` 只读取传入 JSON 对象，不访问数据库、网络或设备。输出固定 `field_validation=false`、`control_eligible=false`。测试中的标签和数值均为合成软件向量，不能据此宣称真实工况识别精度。

## 数据与可复现边界

- 训练输入遵循 `condition.training/1`；显式提供特征名称与单位、样本来源身份、带时区的观测时间、人工声明的规则及所有训练参数。未知字段、控制字符、布尔数值、NaN/Inf、超界数值和超出运算预算的任务被拒绝。
- `train`、`validation`、`test` 各至少六条、各包含全部训练类别。三个分区的井集合互斥，样本 ID 与周期 ID 全局唯一，UTC 时间范围严格依次排列。输入分区不会被程序重新随机切分。训练集每类至少两条，保留三个分区各自的井数、样本数、UTC 时间段、类别计数与数据摘要。
- 均值、总体标准差、最小值和最大值只由 `train` 计算。常量维度记录 `constant=true`，标准化值为零。`validation` 仅用于选择权重轮次；`test` 仅用于最后一次比较，改动其标签或特征不会改变模型制品。
- 运算预算在拟合前按契约公式检查，超出 20,000,000 即拒绝，不缩减数据或轮数。种子用于本地 `random.Random`；相同输入和种子得到相同结果。训练摘要记录实际参与拟合与选轮次的训练/验证数据及参数；完整输入和各分区另有摘要。

## 算法与结果

单隐层网络以确定性随机权重起始，隐藏层为 `tanh`，输出层为稳定的 softmax。每轮对整个训练集计算交叉熵与 L2 惩罚，通过反向传播求平均梯度并更新权重与偏置。每轮重新计算训练、验证损失；保留验证损失最低的已训练权重及其轮次。记录种子、每轮损失、执行轮数、最佳轮次与停止原因。梯度更新、权重、输出或损失超出有限界时拒绝，不返回伪造成功。

两种对照方法和 BP 使用同一 `test` 行：

1. 规则基线逐条执行分析人提交的 `le`/`ge` 子句；多规则命中不同类标记 `rule_conflict`，无命中标记 `no_rule_match`。测试标签不会被转换为规则。
2. 中心基线由训练集标准化值求每类中心，以欧氏距离平方选最近类。精确/近似平局按类标字典序选取，并报告 `centroid_tie`。

三者均检查训练特征范围。每维外扩量为 `ood_margin × max(train范围, |train均值|×10⁻¹², 10⁻¹²)`；超出时返回 `unknown`。BP 的最高 softmax 分数低于 `confidence_min` 同样返回 `unknown`。分数仅称“未校准模型分数”，不解释为病理概率。

每种方法报告以真实类别为行、预测类别与 `unknown` 为列的混淆矩阵；每类精确率、召回率、F1、macro F1；接受数、未知数、覆盖率、全行准确率和仅接受样本准确率。没有接受样本时后者是 `null`。同时保留每条测试行的样本 ID、真实类别、预测类别及拒绝/平局原因。指标只描述实际输入测试集，缺少的真实工况不推断准确率。

## 数值制品与推理

制品版本为 `condition.artifact/1`、算法版本为 `condition_bp/1`，仅包含特征、标签、缩放统计、隐藏层维度、两个有界数值权重矩阵和偏置、训练摘要、`research_only` 来源范围。预测前严格验证每个键、维度、有限值、界限及缩放统计一致性。不加载 pickle、不执行动态代码、不从制品读取路径。HTTP 层仅能从当前获批准并选用的训练记录取制品，公开请求不能提交制品；该权限复核由持久化服务负责。

推理输入的样本仍需独立身份与有效时间。推理只返回标签/`unknown`、分数、OOD 特征和原因、输入与制品摘要；无真实标签，故不产生准确率或“独立验证”声明。软件合成样本若与训练身份相同，也不能被当作独立现场证据。

## 软件测试与适用性

`tests/test_condition_studies.py` 覆盖手算混淆矩阵、井/周期/样本/时间泄漏、训练专属缩放、测试标签改动不影响权重、三类隔离样本、XOR 非线性学习、确定性、运算预算、常量特征、规则冲突、低置信、OOD、错维/非有限/越界制品、输入不变。运行方式：使用项目现有虚拟环境执行 `python -B -m unittest tests.test_condition_studies -v`。

依据：[scikit-learn 多层感知机文档](https://scikit-learn.org/stable/modules/neural_networks_supervised.html)解释特征缩放、tanh/softmax、反向传播和交叉熵；[常见数据泄漏说明](https://scikit-learn.org/stable/common_pitfalls.html)支持仅在训练数据拟合预处理；[模型持久化说明](https://scikit-learn.org/stable/model_persistence.html)说明不可信 pickle 的执行风险。本程序为标准库实现，并非 scikit-learn 模型或工业验证结果。
