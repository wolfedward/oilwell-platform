# 生产设备台账：部署、检查与回退

本工作包为 WP-02，响应 Y1-02（数字采集）、Y1-03（安全传输与共享）、Y3-05（集成平台）。台账独立于已有演示井和设备；不会导入演示台账、自动登记陌生上报设备或改变 MQTT 原始入库行为。

## 能力与边界

提供生产井目录、网关/终端组合身份、不可覆盖点表版本、人工审核、时效绑定、登记状态、来源核查、独立权限与审计。管理页面入口为“采集监控 → 生产设备台账”。接收链路仅说明中心多久未收到消息；“台账已启用”不是现场电机运行证据。

本版只观测。平台期望点表与终端实际采用版本分开：后者始终未确认，不下发配置，不执行启停。即使历史样本匹配成功，也不成为自动控制许可。原始 source、质量码和工程值原样保留；核查不会对已换算工程值再次应用 scale/offset。

## 部署前提与身份

使用已有中心 PostgreSQL；先由数据库管理员核实实例、数据库、备份与角色，明确授权迁移，禁止借用现有 MQTT 入库身份提升权限。运行时不建库、不迁移、不自动授权。以下名称是部署示例，不是对当前机器已建角色的声明。

| 身份 | 配置段 | 用途与限制 |
| --- | --- | --- |
| 中心入库 | `postgres` | 维持既有原始消息/测点入库；不增加台账管理权限 |
| 台账写入 | `postgres_registry` | 台账必要 INSERT/限定列 UPDATE/SELECT；不能改删审计、不可变快照或原始测点 |
| 只读查询 | `postgres_query` | 台账和必要中心原始表 SELECT；不能写入 |
| 独立迁移 | `postgres_migrator`，独立文件 | 仅显式迁移使用，负责 schema/扩展/授权；绝不作为应用运行身份 |

三个运行账号必须不同，指向完全相同 host/port/database；不用主机别名替代这一核对。写入/查询账号不能是数据库、schema、扩展或表所有者，不能通过角色成员关系、PUBLIC、列级授权、原始分区授权或触发器绕过权限取得更大能力。预检严格拒绝这类账号；需管理员审查既有授权后处理，应用不会自动 REVOKE。

## 配置

沿用 `server.py --center-config <中心配置路径>` 或 `PLATFORM_CENTER_CONFIG`。从 `config/center.example.toml` 补齐 `registry`、`postgres_registry`、`postgres_query`，不建立第二套端口或配置入口。密码仅引用系统凭据或环境变量，禁止明文写入 TOML；远程数据库使用 `sslmode=verify-full` 和受信 CA。原有中心配置错误仍按原流程处理，新增台账配置错误只让台账不可用。

`registry.enabled=false` 或未配置时，认证后能力为 `enabled=false,status=disabled`，隐藏导航，直接访问页面提示未配置；启用但预检失败时状态 unavailable，接口返回 503。能力响应不包含数据库地址、账号、密码或详细配置。

`allowed_origins` 为精确来源列表，含协议、主机和非默认端口，不含路径、尾斜线或通配符。HTTP 80、HTTPS 443 可省略；显式填写默认端口时按浏览器规则归一化，例如 `https://platform.example:443` 保存为 `https://platform.example`，8443 等非默认端口仍严格区分。主机名转为小写，IPv6 压缩表示。浏览器写操作必须精确匹配 Origin；无 Origin 的非浏览器调用必须使用有效 Bearer 认证，仍执行岗位权限检查。不信任 Host 作为来源白名单。反向代理必须保持浏览器 Origin 与授权配置一致。默认端口行为依据 [WHATWG URL 标准](https://url.spec.whatwg.org/#port-state)。

非回环站点必须通过受信 HTTPS 提供页面和 API，以保护会话并支持浏览器安全上下文中的随机幂等键生成；本机 localhost/127.0.0.1 联调可用 HTTP。开放端口、反向代理和 TLS 证书须按实际网络部署另外审查，不将本机联调配置直接暴露公网。

阈值：默认 `online_seconds=120`、`delayed_seconds=900`、`clock_tolerance_seconds=300`，均不超过 86400；在线阈值为正，延迟阈值更大。链路以最后中心接收时间计龄：从未上报 / 在线 / 延迟 / 离线 / 接收时钟异常。样本测量时间过度超前单独影响核查，不把延迟补传改成现场在线。

## 显式迁移与启动检查

以下命令中的库名和角色须先改成管理员确认的目标。`--expected-database` 是硬核对，不得省略或用生产库执行测试重置。迁移配置只包含迁移身份凭据引用；执行前完成备份，并记录实际服务器/库/角色。

```powershell
.venv/Scripts/python.exe -m backend.registry.migrate --config config/registry-migrator.local.toml --expected-database oilwell_platform --writer-role oilwell_registry_writer --reader-role oilwell_query --check
.venv/Scripts/python.exe -m backend.registry.migrate --config config/registry-migrator.local.toml --expected-database oilwell_platform --writer-role oilwell_registry_writer --reader-role oilwell_query
```

未迁移时第一条应返回 `registry.schema_missing`，不是部署成功。第二条显式创建 `device_registry` 和 `btree_gist`、记录迁移摘要，再对已存在角色授权；不创建数据库或用户。若 schema 已存在但版本/摘要不匹配，停止并查明原因，不覆盖、不自动修复。schema 与授权是两个阶段：授权失败时已建 schema 可保留，修复账号后重跑，不能删 schema 掩盖失败。

迁移 v1 文本按 LF 规范化 SHA-256 为 `956a09531eabc19d17040c87168adb4a7fb440db1fbd08788497008a382a7c81`。`--check` 核对目标、版本和摘要；它不是完整运行权限检查。实际应用启动再用独立写入/只读连接进行只读 catalog 预检，核对关键约束、索引、触发器、角色和有效权限。数据库管理员仍是信任边界；摘要不证明数据库免于管理员篡改。

新正式台账的 `wells` 和 `devices` 应均为 0；用授权只读连接确认，不向 public 原始表插入测试样本。登录后检查 `/api/auth/me` 的 registry 能力、`/api/registry/wells` 与 `/api/registry/devices` 的空列表、健康接口、旧中心查询及入库服务正常。再由获授权人员登记经过核实的实际身份。

## 操作、并发和核查

对象版本、修订号、点表版号、原始序号均使用十进制字符串；不要转为 JavaScript Number。设备身份为 gateway_id + device_id，不是单独 device_id。人工启用需要有效井绑定、已批准的期望点表和本次核查依据；迁井、解绑或替换期望点表会关闭旧时段，并将已启用台账停用待复核。退役为终态，不释放组合身份。

所有写入先校验登录、权限与 Origin，事务内写业务、不可变审计、回执和修订号。网络中断、超时或服务器/网关 5xx（包括 500/502/503/504）后不能断定失败，须保留原正文和幂等键重试；同键不同正文拒绝。页面只在内存保留未决操作，不承诺浏览器重启恢复。确认后重新读取当前实体，不能用旧重放结果覆盖当前版本。401/403 先恢复登录/权限再核查；409 重新读取后发起新操作；422 修正输入。

历史按测量时刻的半开区间 `[开始,结束)` 核查；晚到样本仍归属当时井号/状态/期望版本，不套用当前关系。界面为北京时间 +08:00，保留 UTC 原值及微秒。来源核查必须指定完整组合身份或井 UUID，二者不能混用；默认 24 小时，最长 31 天，默认每页 20、最大 200，偏移上限 100000。

翻页保留首屏修订号、接收截止时间；原始样本还保留 query_total。台账变化或接收集合变化返回 409，要求刷新，不静默拼接不同快照。它不是跨 HTTP 请求持有同一个数据库事务；时间边界、计数和修订号共同提供可解释的一致性门禁。

## 故障恢复与禁用回退

运行日志只记录模块状态/安全错误码/请求标识，不打印连接密钥。503 时先核查配置引用和目标实例，再由管理员核查迁移摘要、读写身份与权限；不要把“暂不可用”处理成空列表或设备离线。修复后重新执行检查，并受控重启应用加载 runtime；本模块不要求重启 Broker/PostgreSQL。

回退：将 `registry.enabled=false`，受控重启应用，检查健康、原中心入库/查询正常、台账导航隐藏。保留 schema/审计/回执/时效历史，不删除数据，不回放测试数据，不回滚冻结演示目录。若需要数据库灾难恢复，使用既有经验证的备份流程，本包不替代备份恢复演练。
