# WP-05A 常规游梁式抽油机功图反演与双图验证设计

日期：2026-10-09。状态：首版范围已确认，书面设计待用户审核。

本模块面向生产工程师、算法工程师和业务复核员，把有来源的设备参数、同步电功图、反演结果和独立传感器示功图连接成可追溯的分析流程。首版交付可计算、可解释、可复核的软件能力，不承诺缺少现场试验依据的反演精度，也不直接控制设备。

用户已确认先做设备参数档案、物理反演、双图误差评估及人工复核和回退，随后再做 BP 等模型比较。研发依据仅为任务书年度工作任务 Y1-01、Y1-04、Y3-06；专利、奖项等绩效目标不进入本设计。原文“冲刺测量”按用户已确认的冲程、冲次及周期同步测量理解。

## 1 交付范围与兼容边界

### 1.1 首版支持范围

本设计将已确认的“常规游梁式”范围细化为以下可验证组合，供本次书面审核确认：

- 常规曲柄平衡、刚性四连杆、以游梁支点为圆心的圆弧驴头；机构分支、转向和几何零位已确认。
- 工频直接供电的异步电机，机械传动比固定；输入为电机端三相总有功功率的同步、带符号、中心时间戳窗口均值。
- 实测曲柄角、载荷和位移同时存在于 WP-04 已批准配对及冻结数据集成员中。载荷和位移只作为独立对照，不进入同次预测。
- 允许周期内曲柄速度变化，但必须有有效的角度测量、惯性参数、独立损耗标定与适用范围证据；模型不因输入“平均冲次”而自动假定恒速。

首版不支持 VFD 输入端或直流母线功率反演，不从原始六路电压电流自行合成功率，不支持气平衡、异相曲柄等其他机构，不用参考位移反求预测相位。此类数据保留在原始数据平台，返回具体不支持原因，不能自动降级为旧演示算法。厂家可按本输入合同准备接入数据；后续扩展需新增模型合同版本。

### 1.2 本次成品

1. 最小抽油机及驱动组合身份、不可变参数版本、有效期和独立审核。
2. 从冻结配对数据到地面悬点载荷与位移的纯计算内核，含逐点状态和中间量。
3. 单成员计算请求、耐久结果、失败恢复和当前适用性检查。
4. 双图工作台、有效区段与补绘区段分开的误差报告、参数版本比较。
5. 参数及算法选用记录、复核、撤销和有条件回退，及受审计导出。
6. 独立数值基准、隔离集成测试、浏览器交互测试和部署回退说明。

不在本次范围内：BP 训练、自动参数辨识、工况分类器生产化、产液计量、井下泵功图求解、节能优化、设备启停、硬件保护、通用任务调度平台。它们仍属于后续工作，不因本模块交付而完成。

### 1.3 与已有成果分离

设计基线为 WP-04 发布提交 `5bae93ec43d006aed56f21d98d6c5a3b5ff23056`。新代码在既有独立工作区实施；不改冻结演示目录、归档或标签，不自动合并、推送或部署。

`backend/algorithms/dynagraph.py` 和 `backend/services/analysis.py` 保留兼容用途；生产入口不得调用其固定效率、简谐机构、120 点归一化或缺参补默认值的路径。原 SQLite `model_runs` 不作为生产反演的证据库。生产模块单独命名、单独数据表、默认禁用；不得把旧演示结果迁移成现场结果。

## 3 机械身份与不可变参数

### 3.1 机械配置身份

新增 `assembly_id`，表示一套明确的抽油机、驱动电机与传动组合。它不等于井号、网关 ID 或传感器序列号。身份包含厂家、型号、资产或制造编号、机构类型、来源类别和安装证明。更换驱动或影响本模型的机械构成时建立新配置版本；移井、更换平衡配置和参数修正保留历史。

机械配置与生产井采用不重叠的半开有效期 `[valid_from, valid_to)` 绑定。生产用途要求该绑定覆盖包含时钟不确定性的整个观测区间，并与 WP-04 同期井绑定一致。软件试验使用独立试验身份，不能批量激活到生产井。

### 3.2 参数包

保存为 `inversion.parameter-set/1`，采用固定字段、SI 单位和规范十进制字符串；拒绝未知字段、非有限值、重复 JSON 键和可执行表达式。每次保存产生新不可变版本和内容摘要，不覆盖旧正文。空值可保存在草稿，提交审核前必须完整。

每个参数版本明确绑定机械配置版本及物理有效期 `[valid_from, valid_to)`，覆盖包含时钟不确定性的整个观测区间。物理有效期与编制、批准、选用时间分别保存；后来批准的历史参数必须有当时配置的证据，不能将批准时间当作追溯适用依据。配置变化产生后继版本，不能修改旧版本使其覆盖不相容的时段。

| 参数组 | 必须表达的信息 |
| --- | --- |
| 机构 | 曲柄轴与游梁支点的相对位置、曲柄半径、连杆长度、后臂长度、驴头圆弧半径、装配分支、驴头位移方向 |
| 相位 | 编码器通道绑定、单位、角度展开方式、向上竖直曲柄对应读数、实际旋转方向及独立安装依据 |
| 重力和惯性 | 曲柄及平衡重组合的惯量和一阶质量矩，游梁及驴头组合绕支点惯量和一阶质量矩，连杆等效质量、质心位置及质心惯量 |
| 上游传动 | 固定总速比、折算到曲柄坐标的上游转动惯量、折算计算依据、部件归属清单 |
| 损耗 | 电机及传动的双向功率损耗表、曲柄机构剩余摩擦模型、独立标定来源及不重复计入的边界 |
| 适用区间 | 电机供电方式，功率、转速、加速度、温度及供电条件范围，允许的运动拟合残差、带宽和平均窗口范围 |
| 误差政策 | 参数和测量不确定性依据、非杆载荷等效转矩误差包络、转矩因子误差包络、允许载荷误差和最小可观测覆盖率 |
| 证据 | 来源机构、日期、附件摘要、标定数据引用、适用期、编制人、独立复核人和审核理由 |

以上字段均须有单位和来源。明确的零惯量、零损耗、零不确定性也属于需说明的参数，不是缺省值；理想零值可用于标明来源的软件数值试验，不能借此宣称现场误差为零。参数不从网上案例或图形轮廓自动填写。

机械惯性和损耗按部件归属清单分配一次：上游电机、传动部件与下游曲柄、游梁、连杆不重复计入。杆柱及液柱已经包含在目标悬点载荷中，不再增加一个“静载荷常数”。本版采用重力势能表达，不同时叠加另一套 structural unbalance 经验项。

### 3.3 审核和选用

参数状态为 `draft → submitted → approved/rejected`；批准后可 `revoked`。草稿修改生成后继版本；提交后正文不可编辑。编制和提交可由同一人完成；复核人必须同时不同于编制人和提交人，管理员拥有全部功能但不绕过独立复核规则。

参数“批准”说明记录经过复核，不代表已完成现场精度认证。来源为 synthetic 的参数只能用于软件试验；没有适用期或独立标定依据的版本不能用于现场输入计算。

每个机械配置可维护有版本的选用记录，记录参数版本与算法版本。回退是追加一条选择已批准、兼容、未撤销版本的事件，不改写原记录；它不修改机械参数在历史观测时段的物理有效性，也不把已撤销结果恢复有效。只有一个可用版本时，页面明确无可回退目标。

## 4 输入包及数据适用性

### 4.1 服务端生成输入包

首版一次计算一个冻结数据集中的一个 pair 成员。请求只提供固定 ID、摘要和期望版本；浏览器不能提交任意曲线数组作为生产输入，也不能指定本机文件路径、SQL 或远程下载 URL。

服务端生成 `inversion.input/1`，至少包含：

- 数据集版本及内容摘要、成员序号、pair ID/内容摘要/批准修订、两侧质量证书摘要、完整 selection。
- 每个 capture 的中心身份、声明身份、manifest 摘要、规范文件长度和摘要、来源类别及物理周期标识。
- 各通道的采样配置、标定、同步和来源证据的 ID/内容摘要/审核版本，以及不可变正文副本。
- 同期井/设备/机械绑定和适用性检查结果；使用点表时额外固定点表及分配版本。
- 同期运行条件快照及证据，包括损耗标定所要求的温度和供电条件、量值/界限、单位、观测时段、来源和不确定性。
- 参数版本、审核版本、算法制品摘要、评估政策摘要、选用事件版本、操作者和请求身份。

输入包内容摘要覆盖上述固定信息，计算结果引用该摘要。结果保存必要的固定正文和样本索引映射，不复制整个数据集或全部原始文件。

### 4.2 必需通道

| role | quantity | 接受的校准后单位 | 首版含义 |
| --- | --- | --- | --- |
| `active_power` | `total_active_power` | W 或 kW | 电机接线端的三相总有功，保留回馈负值；`window_mean` 且中心时间戳 |
| `crank_angle` | `crank_angle` | rad 或 deg | 独立角度传感器的瞬时角度，包含旋转方向和零位证据 |
| `load` | `load` | N 或 kN | 独立悬点载荷传感器瞬时值，仅供比较 |
| `displacement` | `displacement` | m 或 mm | 独立悬点位移传感器瞬时值，仅供比较及已有物理周期界定 |

第一版不接受其他单位拼写的猜测性转换。额外通道不进入预测，仍继承冻结 selection 的质量约束。用于厂家接入的 profile 将这四个角色及各自采样率、范围、标定和同步要求显式列出；不为已有不合格数据放宽门禁。

温度、供电等适用条件由同期独立监测或覆盖该周期的受审核运行记录证明，作为输入快照的准入证据，不要求一律成为高频波形。条件的测量不确定区间必须落在标定适用域内；只有参数表写了适用温度、却没有本次运行条件依据时拒算。不从功图对照结果反推这些条件，也不以厂家典型值替代实测或受审查的条件证据。

总有功测量必须声明电气接线、符号、平均窗口、带宽及证据，校准后的时间点必须是该窗口的物理中心。WP-04 时间校正仅应用一次，不再次按说明文字重复扣除滤波延迟。语义无法确认时返回 `power_time_semantics_unknown`。本版不把起点/末点标记均值或 RMS 转为瞬时功率，不用 5 秒标量插成周期曲线。

电机端、VFD 输入端和机械输出是不同测量边界；厂家的测量资料亦分别定义这些位置。[Yokogawa 电机与变频驱动测量](https://tmi.yokogawa.com/library/resources/white-papers/electrical-motor-and-variable-speed-drive-testing/)

### 4.3 读取与准入

使用 actor 绑定的 `research` 导出与现有受审计原文读取，验证规范文件及所有被使用数据块，取得固定 selection 所需完整样本和证据正文。允许按文件块扫描，不能把显示摘要当原始值，也不能读取 selection 以外的通道或区间来补足缺失输入。读取授权先于字节使用；读库账号不能绕过审计直接提取原文表。

下列条件任一不成立均拒绝定量计算：pair 当前批准且修订匹配、完整质量证书相符、原始文件完整无冲突、来源可验证、采样和标定未撤销、同期设备与井有效、机械配置适用、算法与参数批准、信号/带宽/时间语义受支持、权限仍有效。

`software_pair_test` 与 `field_pair_input` 始终分开保存和筛选。软件试验可以运行显式 synthetic 理想模型，但不能转换为现场来源；现场输入通过采集质量门禁也不等于反演已经达到现场精度。

## 5 物理模型

### 5.1 坐标与机构

内核采用 SI：长度 m、载荷 N、功率 W、时间 s、角度 rad、惯量 kg·m²。页面另行换算 kN/kW；所有两位小数仅为显示格式，不参与计算或摘要。

取曲柄轴 `O=(0,0)`、游梁支点 `B=(bx,by)`，竖直向上为 y 正向。θ 从曲柄向上竖直位置起，沿设备实际旋转方向递增；`d=+1` 表示顺时针，`d=-1` 表示逆时针。编码器安装映射由参数版本给出。不得把竖直曲柄位置默认成上下死点。

曲柄销 `P=(d r sinθ, r cosθ)`。后臂连杆铰点 `R=B+c(cosβ,sinβ)`，满足 `|R−P|=l`。通过两圆交点和固定装配分支求 β，并连续展开；整周应保持同一分支，不能遇到跳变时临时切换解。

圆弧驴头悬点位移为 `s=σ a(β−βref)+sref`，σ 由安装方向确定，选取零点使本机构下死点位移为零。转矩因子 `J=ds/dθ`，单位 m/rad。它从真实四连杆导出，不使用冲程一半乘正弦的通用替代式。

整周几何校核包含长度闭合、两圆分离/包含/相切、分支连续、预测冲程、上下死点、导数条件数及安装方向。机构闭环退化与悬点载荷死点是不同错误：前者拒绝该参数版本，后者按逐点不可观测处理。

### 5.2 运动与时间

曲柄角独立于参考功图。首版按原始时间展开角度，要求一整周运动、方向一致且没有不可解释的反转；不把样本序号映射成实际角度。

在目标功率中心时间上，用同一 selection 中相邻七个有效角度样本做三次局部最小二乘拟合，同时求 θ、ω 和 α；时间先平移、缩放后求解。内部使用包围目标的样本，端部只在选择区间内有足够样本时采用单侧窗口。记录原始索引、窗口长度、残差和数值条件；不跨无效点、缺口、捕获边界或周期外推，不隐式加入周期接缝数据。参数版本固定最大时间跨度、最大角跨度、残差和条件数上限，超过时该点无效。

绝对时间及采样间隔保留 WP-04 的整数/有理数表示，先精确计算相对时间再转入数值求解，不将 Unix 绝对时间直接转换为浮点后相减。功率均值的完整支持窗口及其时间不确定区间超出选定周期时，该点无效，不能只因中心时间在区间内就参与反演。

角度样本与功率中心支持区间不足时不造点。速度必须大于带不确定性裕量的批准下限；停机、起动、制动和电磁暂态不属于本版准稳态电机转换范围。预测速度、加速度和功率必须处于损耗标定的适用域。

### 5.3 机械重力与惯性

令 `U(θ)` 为下游曲柄/平衡重、游梁/驴头和连杆的重力势能，`M(θ)` 为这些部件折算到 θ 的等效惯量。不包含杆柱及液柱，不包含第 5.4 节已计入的上游惯量。

由刚体位置求势能、由速度系数求惯量。首版按三组等效刚体表达：

- 曲柄和平衡重组合：绕 O 的总惯量及参考方向的一阶质量矩。
- 游梁和固定附件组合：绕 B 的总惯量及梁坐标的一阶质量矩。
- 连杆组合：质量、沿连杆的质心比例 λ、绕质心惯量；质心 `C=P+λ(R−P)`，连杆姿态为 ψ。

因此，`M=Icrank + Ibeam(β′)² + mp |C′|² + Ip(ψ′)²`。各组势能由其质心高度或质量矩计算，`U′=dU/dθ`。惯性转矩为 `M α + 0.5 M′ ω²`；即使曲柄匀速，游梁和连杆仍可能存在惯性项。

公开的抽油机转矩研究区分重力、平衡和转动/摆动惯性，并要求考虑变速工况。这里采用统一 SI 广义坐标表达，是本项目的模型设计，不直接套用论文案例的设备参数或英制系数。[Takacs 等的原始研究](https://link.springer.com/article/10.1007/s13202-015-0172-z)

### 5.4 电机端功率到曲柄转矩

首版模型标识为 `beam_energy_balance/1`。工频电机端总有功 `Pe` 为正表示输入电能，负表示回馈。曲柄方向统一为正速度，驱动转矩仍可为负。

电机及上游传动热损耗 `L(Pe,ωm)` 为非负耗散功率。采用有来源的二维网格表，以带符号 Pe 和 `ωm=ratio·ω` 为坐标，双线性插值；不得域外外推。正负功率跨越区间必须有相应标定覆盖，不能用同一个正向效率乘负功率。每轴 2—64 个严格递增节点，最多 4096 个值；每格具备标定误差包络和适用条件证据。

上游转动动能使用折算惯量 `Iup`，其变化功率为 `Iup ω α`。电机电磁储能和传动弹性动态在本版不做在线状态估计，而必须由独立试验在准稳态适用域内给出等效转矩残差上界；缺少上界、或不在试验条件内时拒算，不默认它们为零。

名义曲柄输入转矩：

`Tdrive = (Pe − L) / ω − Iup α`

曲柄机构剩余摩擦用已标定的 `Tc + bω` 表达，`Tc≥0、b≥0`；上游损耗表不能已经包含同一摩擦。若此模型不足以覆盖实际机构，参数不可批准供现场使用，应新增模型版本。

电参数反演研究将电机、机构、平衡和损耗共同纳入，并用独立测量校正模型偏差；这支持本项目建立有证据的物理基线，不提供本项目井的损耗或准确率。[Wei 与 Gao 的原始研究](https://onlinelibrary.wiley.com/doi/10.1155/2018/6730905)

### 5.5 载荷求解与不可观测区

令 `N=Tdrive−U′−Mα−0.5M′ω²−(Tc+bω)`。目标是绝对悬点拉力：

`Fhat = N / J`

不再加静杆载荷、不裁去负功率、不强制载荷落在模板范围。载荷超过批准工程范围时保留诊断中间量、标记不适用，不裁剪成看似合理的值。

误差门禁使用独立审核的非杆载荷等效转矩误差上界 `uN` 和转矩因子误差上界 `uJ`，二者覆盖各自声明适用域内的测量、时间对齐、标定、数值微分和未建模动态。它们是有依据的误差包络，不是自动生成的置信概率。内核另加数值求解误差预算，不以插值平滑降低原有不确定性。

当 `|J|≤uJ` 或 ω 的不确定区间含零时，该点不可观测，不执行除法。其余点使用

`uF = (uN + |Fhat| uJ) / (|J| − uJ)`

作为已给定误差包络下的载荷误差界；超过参数批准的 `max_load_error_N` 时仍无效。uN/uJ 的依据不充分时，现场计算拒绝；软件理想试验可以使用明确标注的已知界。页面同时显示假设条件，不把此界称作已实测的现场误差。

不能通过给分母加小数、固定屏蔽 10°、自动调平衡量或使用参考载荷来“修好”死点。每点状态至少包括 `valid`、`unobservable`、`input_gap`、`motion_unreliable`、`outside_model_domain`。

## 6 对比方法与展示补绘

### 6.1 独立性

预测函数只接收电功率、角度、参数包和固定算法政策；函数签名与数据结构不包含参考载荷或参考位移。参考数据由独立比较器读取。已有物理周期边界可以用于选定比较窗口，但不能用参考位移调整预测几何零位、相位或预测冲程。

损耗和误差包络的标定记录必须列出来源数据与时间/物理周期范围；不得由当前评价周期拟合。与本次成员重叠时拒绝独立评价。外部标定资料无法证明范围独立时可保留研究记录，但不能标为独立现场验证。WP-05B 再处理自动参数辨识、训练划分和 BP，不在本版暗中调参。

### 6.2 比较坐标与指标

目标时间为原始功率窗口的中心时间，不重采样为固定 120 点。参考载荷和位移只允许在有效相邻原始样本之间做线性插值，并保留两端索引、权重与标记；最大间隔受批准政策限制，不跨缺口、死区或周期外推。窗口平均功率造成的载荷等效平滑误差必须包含在模型误差包络中，不能宣称已恢复更高带宽的瞬时载荷。

只在预测及参考均有效的连续区段计算主指标。MAE、RMSE、偏差按实际时间积分加权；最大绝对误差另行报告。上/下冲程由 `ds/dt` 的正负确定，不默认 0—180° 是上冲程。报告载荷误差、位移误差、有效时长/覆盖率、无效原因分布、上下冲程指标及各自样本数。

参考量恒定时相关系数返回 null 和原因，但仍可计算有充分支持的绝对误差。样本不足或有效时长为零时，按各指标的定义分别返回 null，不把无法计算写成 0 或 1 表示完美。相对误差分母不足批准阈值时返回绝对误差和百分比不可用，不使用极小分母。

功按时间顺序计算 `∫F ds`，保持方向符号，不按位移排序。存在未覆盖区段时仅报告有效区段功，完整周期功为 null；该量是悬点功，不能标为井下有效功、泵充满度或计量产液。

### 6.3 补绘与图表

默认只画有效反演区段与独立实测曲线。用户可勾选“显示死点补绘”，使用两侧有效点之间的线性插值，满足固定的最大时间/角跨度后以虚线显示；跨周期接缝的补绘另标“周期性假设”。不跨普通输入缺口补绘，不把参考载荷用于补点。

补绘值是单独派生序列，不覆盖原始 null 和逐点状态。若显示含补绘的完整周期功，只能称“补绘估算”，不进入主误差、能量一致性或现场通过判定。补绘区段的对照误差单独显示。

两条图可分别开关。横轴位移 m、纵轴载荷 kN；图形比例可调整但不改变数据。常态不显示大圆点，悬停或键盘聚焦时才显示点、两位小数坐标、来源、状态及原始索引。页面周围显示井/机械身份、采集时间、冲程、冲次、载荷范围、有效覆盖率、参数/算法版本和复核状态；尚未接入生产工况模型时不伪造故障诊断标签。

## 7 服务结构与持久化

新模块建议位于 `backend/inversion/`，细分契约与纯数值内核、输入适配、参数服务、运行服务、比较、结果治理、API/运行时。前端位于 `frontend/inversion/`，不向原演示分析大文件继续堆叠生产逻辑。

PostgreSQL 新建独立 `inversion` schema，使用显式迁移和最小权限 reader/operator；不在启动时自动 DDL，不提升采集入库账号权限。最小持久化对象如下：

| 对象 | 保存内容 |
| --- | --- |
| assemblies 和 assignments | 机械配置身份、井绑定与不重叠有效期 |
| parameter_versions 和 reviews | 不可变正文/摘要、编制/提交身份和追加审核记录 |
| model_versions 和 selections | 安装包内模型及算法政策摘要、批准/撤销、按机械配置选用历史 |
| run_requests 和 attempts | 固定请求/输入身份、状态、运行所有者和失败原因 |
| results 和 result_chunks | 不可变输入快照、逐点结果、中间量、指标及内容摘要 |
| result_reviews 和 restrictions | 追加复核及撤销事件、当前不可用原因 |
| audit 和 receipts | 操作者、理由、请求幂等和原子提交记录 |
| capacity 和 state_head | 工作容量、预留资源及修订版本 |

文档附件复用已有受审计附件能力；参数包固定附件 ID、摘要、用途和来源说明。文件类型/尺寸继续受现有限制，不执行文档内容、不自动访问附件内 URL。参数审批验证内容依据，文件摘要本身不证明真实性。

## 8 单成员运行与故障恢复

### 8.1 有界执行

首版采用持久请求加一个独立工作进程，不引入 Redis/Celery 或通用调度器。HTTP 创建请求只做当前权限、固定身份和容量检查，提交请求/审计/幂等回执后返回 202；由工作进程读取已提交请求。

默认运行限制为一个执行槽、最多 16 个等待请求；每请求只处理一个 pair、最多两个 capture，继承 WP-04 每 capture 的 16 MiB 解码和 32 MiB 原文上限。四个必需通道各最多 32768 个 selection 样本，超过直接拒绝，不隐式抽样。输入/结果暂存上限分别为 64 MiB 和 16 MiB；请求政策 JSON 上限 256 KiB。这些是首版保护限额，不是生产容量承诺。

工作进程独立于 HTTP 进程，任务截止时间默认 180 秒，单次数据库操作最长 3 秒、锁等待 1 秒；全链路时间计算覆盖原文准备、解码、计算、序列化及提交，不从完成后才计时。主监护进程拥有计算子进程、等待和清理责任；超过期限或资源限额应终止本次所有者并保留失败记录，不能无限后台运行。只管理本次明确创建的进程，不按进程名清理。

运行子进程不访问任意网络或动态加载用户代码；输入只来自固定数据库适配和已安装算法。暂存目录使用随机、受限、本机非公开路径，不使用浏览器给出的路径。失败暂存按可追溯策略清理；结果已提交前不删除唯一输入证据，完整原文仍由 WP-04 保管。

### 8.2 状态及幂等

运行状态为 `queued → running → completed/blocked/failed/cancelled`。`blocked` 表示输入、权限、依赖或适用范围不合格；`failed` 表示运行资源或内部错误。拒算也要有可读的缺失清单和固定请求身份，不伪装成空图成功。

同一操作者和 Idempotency-Key、同一请求正文返回同一 run ID；正文不同返回 409。连接断开或未知 409 时客户端保留原 key 和正文，先查询原请求，不自动换 key 重算。结果唯一约束绑定 run ID 和获准的 attempt generation，不能由迟到的旧工作进程覆盖新结果。

每次领取记录所有者和 fencing generation，心跳不延长固定的总截止时间。重启只将明确失去所有者的 running attempt 标记 failed，并记录 `worker_interrupted` 原因，其 run 同时进入 failed；首版不自动重跑，用户显式重试生成后继 run 并重新检查依赖。已提交结果若 HTTP 回复丢失，通过原请求查询恢复；不生成重复结果。取消和最终提交竞争采用同一受锁状态检查，只能有一个终态。

### 8.3 计算与提交边界

耗时文件读取、解码、几何和序列化在业务锁外完成。输入准备时、最终提交时、批准/导出时均检查当前适用性；结果读取返回历史复核与当前限制两个独立字段。

需要同时检查 WP-04 与机械历史的操作，统一按以下顺序加锁：waveform dependency guard、共享 registry history、inversion dependency guard、waveform payer/capacity、inversion capacity、按稳定 ID 排序的依赖行。只需要某一子集的写入者也不得反向获得已跳过的锁；不得在反演事务持锁时再调用会自行开启另一写事务的 waveform 服务。

以 cursor 级的内部适配封装复用 `DatasetContext` 当前检查，在同一短事务内核对原有及新增依赖。结果、摘要、审计、容量结算和回执一次提交，失败全部回滚；任何字节作为可用结果输出前，提交必须成功。部署时同时安装使用该锁约定的适配代码和权限迁移，版本不匹配则禁用新模块。

## 9 结果审核与算法回退

`completed` 只代表软件执行完成。结果初始为 `unreviewed`，可由独立复核员批准或驳回；批准记录可撤销，正文永不覆盖。复核员看到独立来源、参数依据、无效区段及误差，不仅看到两条曲线。

批准不自动授予整井/跨井模型准入。结果分别显示：软件运行状态、来源类别、人工复核状态、当前适用性、现场验证状态。现场验证状态首版最多为“单次现场对照记录”，不能由一次低误差自动变成“生产精度已验证”。量产或现场应用需另行确定试验方案、样本规模、跨井/跨时间独立性和精度门槛。

参数、算法、校准、pair 审核或观测期间的台账事实发生相关改变后，旧结果保留，但当前状态为 restricted，并列出原因。单纯“现在换了设备”不必否定过去有效观测，应比较历史观测区间的适用事实；不得仅因全局修订号增加就撤销无关结果。

算法制品首版只从随代码安装的 allowlist 读取，固定实现/依赖/政策摘要；禁止任意 pickle、Python 插件、远程脚本或表达式上传。模型撤销阻止新计算和作为当前工程结论使用；历史记录仍可按证据权限查看。

回退选用动作需写理由并由有权限人员执行，只允许已经独立批准、仍兼容当前输入和参数的版本。回退不重新解释旧结果、不解除任何来源限制、不自动重算或控制设备。未来第二个模型版本引入后用相同流程验证实际回退；首版通过独立测试制品验证协议，不向用户展示假生产版本。

## 10 权限与接口

前缀采用 `/api/production-inversion`，运行时默认 disabled。启用须显式配置依赖数据库、权限、额度及 worker；健康页区分 disabled、misconfigured、ready、degraded。无法启用时页面说明原因，不能退回演示数据。

新增能力：`inversion.read`、`parameters.manage`、`parameters.review`、`run`、`review`、`models.manage`、`models.review`、`export`、`audit.read`，均带 `inversion.` 前缀。管理员具备全部能力和页面；业务复核员负责独立复核；算法工程师可编制参数、运行和提出模型版本，但不自批；生产工程师可读取、运行并按授权复核他人结果；设备运维可编制机械参数证据。具体默认映射沿用新能力一次性授予方式，升级不恢复已撤销权限。

运行及定量导出同时需要 `waveform.read`、`waveform.raw.read`、`waveform.export` 和对应 inversion 能力。HTTP 每次请求先认证/鉴权再查幂等回执；长期运行在领取和发布前重新确认账号、权限和发起者身份。worker 不能以管理员身份代替已失效的请求者。管理员的权限并集不取消自我复核禁令。

当前身份存储与 PostgreSQL 业务事务不是同一个事务域。权限以各操作最新一次成功鉴权为授权时点，记录主体、能力快照和检查时间；无法取得当前权限则拒绝。领取与提交之间不复用旧权限快照，提交后读取及每次导出仍须重新鉴权。首版不承诺跨两种存储的瞬时原子撤权，也不因结果已持久化就向已撤权账号返回内容。

主要资源：

| 接口组 | 用途 |
| --- | --- |
| GET health、assemblies、parameters、models | 可用性、参数及模型查询 |
| POST assemblies、assignments、parameter-versions、submit、review、revoke | 机械身份/参数及追加审核 |
| POST selections 和 rollback | 有版本的模型/参数选用，不下发设备配置 |
| POST runs；GET runs 和 runs/{id}；POST cancel、retry | 单成员计算及状态恢复 |
| GET results/{id}、points、comparison；POST review、revoke | 历史结果、当前限制及复核 |
| POST exports；GET exports/{id} | 固定结果报告、逐点数据与来源索引 |
| GET audit | 有界检索审计事件 |

精确路由和严格 JSON 字段在实施计划中按上述资源细化，不借此扩大功能。所有写入需要幂等键和理由，并检查所依赖资源的期望版本；创建动作使用明确的不存在前提，不能误用更新版本语义。拒绝多重认证头、重复 JSON 键、越界值及未知字段。沿用 Host/Origin 防护、参数化 SQL、有界分页和 no-store 响应。

正常定量导出需所有依赖当前允许；证据导出另用明确 intent 和权限，带 restricted 水印及原因，不作为工程建议使用。导出格式为固定 JSON/CSV，不把原始账户信息、数据库连接或本机路径写入报告；CSV 防公式注入。每次首字节输出前提交审计，失败不输出部分成功。

## 11 页面与交互

新增三个相互连接的页面，不覆盖旧演示诊断页：

1. **机械参数中心**：按井/机械配置查看有效期、参数差异、来源附件、待审核和撤销记录；一键列出尚缺哪些必需参数。

3. **结果与版本复核**：查看输入快照、复核依据、当前限制及选用/回退历史，不提供设备控制按钮。

复用统一导航、角色权限、表单与图表样式。图表默认连续细线，悬停坐标保留两位小数，内部数据保留全精度；不能把显示缩放或降采样反写计算结果。导出的点始终为完整计算点和状态，不能导出页面抽样后冒称原始结果。

未计算、数据不合格、计算失败、未复核、已复核但当前受限必须分别显示。空状态给出可执行下一步，例如补角度通道、提交参数证据、重新建立包含角度的配对，而不是用合成成功图填空。

## 12 验证与验收条件

本模块采用用户已选定的分层验证：每个功能运行针对性测试，关键集成点进行独立审查及一次必要的全量回归，不在文档或无行为变化后重复长时间实验。

### 12.1 纯数值验证

- 四连杆用独立两圆交点实现与已知几何案例核对，检查整周分支、转向和坐标变换；导数与独立数值差分、虚功关系核对。
- 势能/惯量模型用独立刚体能量表达和匀速/变速案例核对，检查上游/下游重复计入、单位和绝对载荷定义。
- 电功率、损耗和储能使用独立手算向量，覆盖驱动、回馈、跨零功率及域外拒算；正反算闭合仅为软件一致性测试，不作为独立现场精度证明。
- 角度拟合以解析运动求导的已知解核对，覆盖噪声、角度回绕、反向编码、时间偏差和窗口不足。
- 死点及误差界覆盖零因子、误差区间跨零、阈值边界、溢出、非有限值、载荷越界；禁止 silent clamp。
- 比较器覆盖时间加权、真实上下冲程、参考缺口、恒定参考、面积近零和补绘隔离；改变参考载荷必须不改变预测结果。

数值容差按算法误差分析及各测试基准声明；不以某个井的现场准确率代替软件容差，也不靠放宽误差来掩盖符号或量纲错误。文献数值只能在完整核对其机构尺寸、角制和单位后作为外部基准，不复制不完整截图数值。

### 12.2 隔离集成及安全验证

- 从明确 synthetic/bench 来源的完整 WP-04 文件、证据、pair、冻结成员开始，走 API 到结果/复核/导出，不以直接插入成功结果替代。
- 覆盖缺参、角度不在冻结 selection、错误井/机械有效期、缺失点表依据、证据撤销、模型撤销、权限撤销和旧请求重放。
- 在准备、提交、批准和导出之间制造依赖变化，验证锁序、无死锁、无受限结果被当作当前有效输出。
- 模拟 worker 退出、请求超时、已提交回复丢失、旧 generation 迟到、重复点击、取消竞争、磁盘/额度不足，验证唯一终态与清理归属。
- 管理员全页面可见但不能自我复核，其他岗位不能越权；未知 HTTP 动作、恶意字段、文件路径和 CSV 注入按契约拒绝。
- 检查冻结演示包/标签不变，生产业务库不写入，不启动现场控制链。

### 12.3 用户可见验收

在隔离软件试验中，可以完成“机械参数编制与独立审批 → 选择冻结配对 → 计算 → 双图及有效区段误差 → 独立复核 → 受审计导出”。随后撤销一项依赖，旧结果仍能按证据方式追溯，当前用途被限制；选择兼容旧版本的回退事件可追踪且不改变历史结果。

页面能准确解释每一个拒算和无效区段，双图显示/悬停/来源信息符合本设计。交付记录明确通过的是软件测试、独立数值验证还是现场测量；没有设备时不填写现场精度或实际节能完成值。

## 13 部署及回退

实现后先使用既有隔离测试环境的专用角色验证迁移、权限和容量；不得清空现有业务库或提高接收账号权限。生产启用是另一次明确授权，不由开发或 PR 合并自动触发。

升级顺序为兼容迁移与 reader/operator 授权、软件与受锁适配、参数/模型元数据、worker、显式启用页面。任一步不一致时禁用新运行，已有采集不受影响。回退先停止接收新运行，关闭明确归属的 worker，保留全部已提交结果和审计；再停用新模块，不删除 schema、不覆盖 WP-04 或演示文件。

初始安装不包含现场机械配置、真实损耗表或冒充已验证的模型。厂家参考配置和测试向量只在明确的软件试验入口提供，其来源标记不可编辑成现场数据。
