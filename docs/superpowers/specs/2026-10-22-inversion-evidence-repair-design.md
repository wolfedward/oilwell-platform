日期：2026-10-22。状态：用户已确认本书面设计；具体实施计划待审阅及选择执行方式，尚未开始代码修复。

设计基线：`f779f96626b233136427c2f0982ef25e15afa66b`，分支 `codex/page-first-preview-design`。本稿承接用户同意的反演技术验证及修复设计，响应任务书年度工作任务 Y1-01、Y1-04、Y3-06，不处理绩效申报目标。

目标是在保留现有阈值的前提下，使新版合成测试输入能够经过有依据的误差检查、真实参数审批、独立工作进程计算、双图比较和受审计导出；证据不足的输入应被明确拒绝。交付结论限定为软件与机理模型内验证，不是现场精度、硬件性能或整个项目完成证明。

## 1 决策摘要

本轮采用“有限合成输入范围的版本化误差合同”，不修饰旧报告，也不把尚未证明的矩形全域包络改成已通过。

| 方案 | 优点 | 主要约束 | 决策 |
| --- | --- | --- | --- |
| 新版有限输入合同与逐窗检查 | 可以逐个核对实际输入、误差来源及真实软件流程；不需要假设现场资料已存在 | 只对列明的合成输入及不确定区间有效 | 本轮采用 |
| 保留独立矩形全域并直接批准 | 对外合同简单 | 现有独立饱和误差假设不能支持 100 N·m；需要另一个完整证明 | 不采用，也不放宽阈值 |
| 新建物理耦合适用域 | 有望形成更广的工程准入条件 | 必须定义可检查的关联谓词、标定依据和完整误差证明，不能用待反演载荷反证自身准确性 | 后续独立设计，不混入本轮 |

具体决定：

1. 新增明确的 v2 参数、模型和结果合同，v1 记录仍按原语义读取。
2. 新测试配置固定角度编码步长为 `0.00000001 rad`，最近偶数舍入；不覆盖旧 `0.000001 rad` 数据，不根据反演结果循环选择精度。
3. 逐窗口计算角度、速度、加速度的确定性误差界，再检查完整转矩分子及转矩因子是否被原有包络覆盖。
4. 初版证据检查只支持本项目已声明的简化刚性机构合成族：下游非零惯性和质量矩仅属于曲柄，损耗为常量，运动为固定周期加正弦速度扰动。不因此宣布一般机构或现场资料获得新准入。
5. 复用现有参数、模型、运行和导出 API；补测试编排器及版本分派，不增加绕过审批的执行接口。
6. 先验证小型包的四个机理正例，再验证明确的拒绝例，最后运行扩展包。正例和拒绝例分开计数。

## 2 已核实的问题与证据边界

### 2.1 矩形域与物理耦合域不是同一声明

独立矩形角点取 `Pe=-250000 W`、`L=1200 W`、`ω=0.11 rad/s`、`δω=0.00001 rad/s`，仅速度扰动引起的转矩差为：

`251200 × δω / [ω(ω−δω)] = 25120000/120989 = 207.6221805… N·m`。

这否定的是允许功率、速度和误差各自独立取值的无条件矩形证明。该角点同时违反固定基准机构及载荷范围的物理耦合约束，不能据此断言全部物理可行输入都无法反演。上轮得到的约 `18.53 N·m` 物理耦合速度项上界也只覆盖一个误差项，不是完整转矩证明。

本轮把原矩形范围保留为外层工程拒绝边界，把新版定量准入范围明确限定为被固定摘要绑定、且逐窗误差检查合格的合成输入。不会沿用 v1 的全域依据文字描述这个新范围。

### 2.2 拟合残差无法代表输入误差

原速度变化案例存在 29 个采样位置，其真实速度偏差扣除旧残差项后仍超过基础预算；原噪声案例为 70 个位置。诊断性提高编码精度后，速度变化案例改善，但未量化的噪声案例仍有 57 个位置超出该诊断指标。

一个七点窗口可加入最大幅值 `5e-7 rad` 的线性角度误差，使三次拟合残差严格为零，同时产生约 `2.133333e-5 rad/s` 的速度误差。因此，正式误差依据必须计入输入误差，不能以残差小、曲线平滑或有限样本差值小代替。

现有 `motion.py` 的速度界包含基础包络、残差放大、时间项和数值估计；`1e-5` 不是总速度误差上限。现有加速度只有名义值域检查，尚未把独立加速度误差传播至惯性转矩。现有几何数值区间也不是传感器角误差的物理包络。

### 2.3 正式测试流程仍然缺失

`tools/testpack/waveform_run.py` 的反演 gate 即使预算通过也返回 `approved_workflow_not_implemented`。后端已存在参数审批、模型审批、选用、运行、工作进程、比较及导出服务；缺的是测试包适配及其可核验的执行证据，不能以直接调用纯计算函数代替这条链路。

### 4.2 结构化证据不塞入图片附件

当前附件服务仅接受 PDF、PNG、JPEG，单件不超过 4 MiB。因此采用以下划分，不扩展通用附件上传类型：

- 参数正文内保存有尺寸限制的 `coverage_contract`，包含机器可读的范围、输入摘要和误差来源；通过原参数 API 保存、提交和独立审批。
- PDF 附件供人审阅假设、方法和离线预算结论，正文固定机器合同摘要。PDF 不是运行端机器检查的替代品。
- 每个运行的逐点详细误差表由工作进程实际计算，保存在结果分块及受审计导出中；不在参数 POST 中塞入 1025 行预填“通过”表。
- 参数正文加请求信封不超过现有 256 KiB。首版一份有限合同只绑定一个 case，不引入跨无限数据包的通配适用域。

`coverage_contract` 必需字段组如下；未知值不能默认零，未知字段及重复键拒绝：

| 字段组 | 必需内容 |
| --- | --- |
| 身份和用途 | schema、`scope=finite_synthetic_input/1`、`source_kind=synthetic`、`purpose=software_pair_test`、pack/case/config/generator 摘要 |
| 输入范围 | 两个预测通道的原始数据摘要、绑定文件摘要、manifest/通道 pin、原始索引、时间序列与质量摘要、周期区间、功率均值支持 |

| 测量和模型 | 角度校准及噪声绝对界、功率量化/计算/平均误差界、损耗误差、参数精确性或误差来源、明确的未建模项 |
| 时间 | 共同相对偏移与逐样本差分时序界及各自证据来源，不假设未知相关性抵消 |
| 运动族 | 固定解析运动定义及其参数、角速度/加速度/三阶与四阶导数上界、有效时间区间、允许的简化机械族 |
| 绑定 | `parameter_core_sha256`、policy SHA、已安装证据检查方法版本及内容摘要、人读附件 pin |

运动模型及其导数界只供证据核验；名义 θ、ω、α 必须从实际角度原码拟合，不允许以解析运动真值替换。载荷/位移参考数组不进入名义预测或误差门禁。正向生成器的物理假设可以用于独立证明其功率生成误差，但不能将参考功图误差反向调成准入依据。

### 4.3 消除自引用，固定全部相关内容

先定义不可由调用者更改的 `parameter_core/1` 规范投影：包含机械身份/有效期/source、geometry、phase、bodies、drive、domain、uncertainty、policy、操作条件和通道绑定等影响数值或适用性的字段；排除 `coverage_contract` 自身、人读预算附件及审批事件。普通物理依据附件仍纳入核心投影。字段以白名单逐项定义，不能用“去掉所有 SHA 字段”这种不确定规则。

生成顺序为：实际波形证据 pin → 参数核心摘要 → 结构化覆盖合同 → 人读预算 PDF → 最终参数正文及摘要 → 独立审批 → 选用/运行。

PDF 固定的是不含 PDF 自身 pin 的机器合同有效载荷摘要；最终合同再固定 PDF pin。机器合同不能反过来引用最终参数正文摘要。完整参数摘要仍覆盖核心、合同、附件和全部其余正文，因此核心投影排除某项不等于该项可无痕改变。

worker 从受审计原文重新计算输入摘要、窗口及预算，不信任客户端的 `passed` 字段。最终输入快照保存完整合同、核心投影版本、原文绑定映射和模型指纹；提交、复核和导出继续执行当前依赖检查。

### 4.4 服务端核验误差依据本身

合同中的 Ωmax、Amax、D3max、M4、噪声和编码前误差不是调用者可以自行声明后生效的真值。服务器安装的检查器只接受固定解析族及预先封存的 case 配置，自行推导运动导数上界，并逐样本用严格区间核验实际原码、舍入、已配置的噪声/时序注入以及功率生成和均值误差。生成器、配置、原文和检查方法必须同时匹配；单独改一份 JSON 并重算其摘要不能建立依据。

调用者提交的界仅是待核验上限：服务端证明的上界不得大于它，且整个必需区间必须被证明覆盖。零界仅在固定 synthetic 定义及编码/计算过程确实证明为零时允许；未建模项未知、检查器不支持、或仅有一份 PDF 的情况均拒绝定量准入。实际名义预测仍不读取解析真值或参考数组。

必须增加缩小 M4、噪声幅度或功率生成误差并重新计算全部用户可控摘要的篡改负例。对应配置即使语法正确、附件存在并经软件账号审批，运行端也须因依据不相容而拒绝，不能仅依赖审批状态。

## 5 误差计算与准入规则

### 5.1 输入与计算分离

计算顺序固定为：

`实际功率/角度原文 → 时间和质量核对 → 七点名义拟合 → 独立输入误差传播 → 分子/因子预算检查 → 载荷求解 → 独立参考比较`。

准入检查器不接收参考载荷或参考位移，也不能读取求解后的 `Fhat` 再决定自己的转矩包络是否成立。只有在 uN/uJ 已经独立成立以后，才能在原载荷误差公式中使用 `|Fhat|`。

### 5.2 七点实际窗口的误差

对每个功率中心，以精确相对秒值 `xj` 构建三次设计矩阵 `Vjk=xj^k`，`j=0…6、k=0…3`。严格有理数算子为：

`W=(VᵀV)⁻¹Vᵀ`，`wθ,j=W0j`，`wω,j=W1j`，`wα,j=2W2j`。

这用于独立权重与数值误差核验，不把浮点正规方程改成生产拟合方法；名义估计仍使用受版本固定的缩放 QR。每个窗口都检查多项式重现恒等式 `Σ wr,j xj^k = r!·1(k=r)`。不复用不匹配的对称中心权重，不跨缺口、不跨捕获拼接、不外推。

定义 `Ej` 为各样本的编码、校准、噪声绝对界，加上差分时序误差转换 `Ωmax·μj`。若扩展后的整个窗口有独立依据支持 `|θ⁽⁴⁾|≤M4`，则：

`br_base = Σ|wr,j|Ej + M4/24 × Σ|wr,j||xj|⁴`，`r=0,1,2`。

`bω_base≤1e-5 rad/s` 才能使用固定基础速度包络。禁止从这个上界减去拟合残差；残差为零的线性/二次输入误差仍被计入。

共同时间偏移 `uc` 与各样本差分误差 `μj` 必须按来源分账，未知相关性按保守区间处理，不重复计入同一项，也不擅自抵消。共同时间项分别使用 `Ωmax·uc`、`Amax·uc`、`D3max·uc`，三阶导数不能用加速度代替。

为保留旧残差附加项的保守性，v2 的物理界定义为：

- `Uθ,physical = bθ_base + residual·Σ|wθ| + Ωmax·uc`；
- `Uω,physical = 1e-5 + residual·Σ|wω| + Amax·uc`；
- `Uα,physical = bα_base + residual·Σ|wα| + D3max·uc`。

残差项只是附加保守项及一致性诊断，不是独立输入误差证明。QR 结果与精确有理数拟合的差分别记录为 θ/ω/α 数值项，随后独立传播到数值预算，不能把数值误差藏入 100 N·m 的物理包络。时间支持、方向、条件数和残差原门禁全部保留。

### 5.3 选择 1e-8 rad 的依据与限制

128 Hz 七点中心窗的速度权重绝对和约为 `149.333/s`，一般近边界窗可接近 `463.238/s`。`1e-7 rad` 半步仅在后者就贡献约 `2.316e-5 rad/s`，超过基础预算；`1e-8 rad` 对应约 `2.316e-6 rad/s`。加速度权重绝对和可由中心的约 `7801.905/s²` 增至偏边界的约 `50712.381/s²`，必须单独传播。

这些数值是选择固定新配置的依据，不是通过结论。实际窗口的时刻、噪声、截断和数值项仍须逐一核验。原 ±1e-6 rad 噪声幅度不缩小，预期因预算不足拒绝。i32 编码必须验证完整周期范围；多圈溢出不得通过悄悄改零位或回绕规避。

### 5.4 从输入误差到载荷

独立名义算子使用完整分子：

`N = [P−L(P,ratio·ω)]/ω − [Iup+M(θ)]α − U′(θ) − 0.5M′(θ)ω² − Tc − bω`。

以精确有理数拟合得到的 θ、ω、α 为独立名义中心，构建包含物理输入误差的 Θ、Ω、Α、P 和参数区间，保守包围 N 与 J。实际 QR 名义值相对此中心的数值偏差单独传播，不重复收费或漏计。首版有限机械族中 `M=Icrank、M′=0`，但上游与曲柄的加速度项均保留；不支持的非零游梁/连杆质量组合返回 `coverage_model_unsupported`，不假装已完成通用证明。

检查至少包括：

1. 整个 Ω、Α、功率及运行条件区间均在批准范围内，Ω 下界严格大于批准的最小速度；不只检查名义值。
2. 整个损耗查询区间都被标定网格覆盖；常量损耗仍计入原 `0.02 W` 误差界。
3. 角度误差进入重力、惯性及 J，速度误差进入功率除法、摩擦和损耗，加速度误差进入全部惯性项。
4. 包含功率量化、编码前误差、平均与瞬时语义差异及所有声明的未建模项。
5. 物理 N 包围相对独立名义 N 的最大偏差不超过 `100 N·m`，物理 J 偏差不超过 `1e-4 m`。未覆盖、区间不可解析或超预算即拒绝该点。
6. 另核对实际数值实现相对独立名义算子的误差，满足 `0.01 N·m`、`1e-7 m`；不能以较宽物理预算吸收计算错误。

通过后仍用原固定包络求 `uF=(uN+|Fhat|uJ)/(|J|−uJ)`，其中分别加入原数值预算；不改为本次较小误差来扩大有效区段。死点、载荷超域、误差限及按原生相邻时间区段计算的覆盖率规则保持不变。

### 5.5 严格数值依据与生成器误差

权重及多项式基准采用精确有理数。三角函数、几何平方根和功率积分的包围拟使用 `python-flint` 的 Arb 球区间运算；这是新隔离运行环境的依赖选择，不在旧安装中追加依赖。实施首步固定兼容版本、wheel/原生依赖摘要、许可和运行环境，验证缺依赖时明确禁用 v2，不回落到裸双精度“证明”。

证据检查使用固定 128-bit 工作精度和预注册计算资源限额；区间仍不可判定时拒绝并保存原因，不通过不断增加精度、删掉难点或放宽阈值寻找通过结果。原生库在有界计算子进程内运行，限制输入位长、样本数、区间细分数及时间；禁止不受限的任意精度请求。

旧生成器用差分步长加倍及 Simpson 16/32 差值作一致性检查，这些差值本身不是严格截断上界。新包须给出独立的解析导数/区间积分余项或经过验证的区间积分包围，把编码前计算误差与 `scale/2` 分开计入。若保留双精度生成值，必须逐一证明其落入上述包围加明确误差预算；不得仅把 `1e-6` 改成 `1e-8`。

独立证明程序不得调用生产 `predict`、`solve_load`、生产运动拟合或生产几何函数来产生期望值。可使用同一可靠区间基础库，但物理公式和权重推导采用独立实现，并辅以精确手算、符号恒等式和变换不变性案例。共享机理假设明确标为模型内验证，不称独立现场验证。

## 7 真实软件工作流

### 7.1 隔离实例与前置检查

只在新建、带所有权标识的 lab 中运行，使用新目录、新数据库/账号及明确空闲端口。仅管理本轮创建的进程；不使用业务 DSN、现有演示库或密封安装做故障注入。

先对封存新包运行独立预算检查，保存实际报告。预注册正例的预算未闭合时停止在 `blocked`，不得提交/批准带失败依据的参数；更不能只翻转现有 gate 的布尔值。这里的 case 级闭合要求全部必需误差来源有依据、所有原生点均已分类，且只按预先规定的逐点门禁计算的可用支撑达到 0.80；不要求死点和周期外均值支撑变成有效点，也不允许按参考 RMSE 挑选样本。正式运行时 worker 仍重算准入及覆盖，离线报告不替代运行端检查或最终比较。

波形按现有 `/api/waveforms` 附件、证据、导入、装配、质量、pair 审批和 dataset 冻结流程处理。所有 UUID、SHA、审核版本、成员序号来自真实响应。记录原包文件 → 运行绑定副本 → 原始归档的摘要映射，不改原包。

### 7.2 反演 API 顺序

下表路径前缀均为 `/api/production-inversion`。

| 顺序 | 动作 | 合格证据 |
| --- | --- | --- |
| 1 | `POST /assemblies`、`POST /assignments` | synthetic 机械身份及 `test:` 测试井绑定 |
| 2 | `POST /parameter-versions`、`GET /parameters/{id}` | 实际参数正文、完整合同及 SHA |
| 3 | `POST /parameters/{id}/submit`，另一账号 `…/review` | 作者/提交者不得自审，固定同一正文及真实审核版本 |
| 4 | `POST /models`，另一账号 `POST /models/{id}/review` | 每个新 lab 登记一次实际已安装 v2 制品；用 `GET /models` 列表核对，不假设存在详情路由 |
| 5 | `POST /selections`、`GET /assemblies/{id}/selections` | 固定兼容的参数、模型及 selection 版本 |
| 6 | `POST /runs/preflight` | 仅 pin 预检，仍为 provisional，不表示已计算 |
| 7 | `POST /runs`、`GET /runs/{id}` | 202 仅为 queued；由所属真实 CLI worker 领取并启动计算子进程 |
| 8 | `GET /results/{id}`、`…/points`、`…/comparison` | completed、实际 result ID、全部分页点、原始比较结果及输入追溯 |
| 9 | 另一账号 `POST /results/{id}/review`，再 `POST /exports` | 独立结果复核、当前适用性检查及受审计导出 |
| 10 | 独立负例撤销依赖、重查/导出 | 历史正文 SHA 不变，当前受限，定量导出拒绝 |

运行请求仍只提供固定 dataset/pair/parameter/model/selection/condition 身份及版本，不允许浏览器上传曲线或结果数组。

反演写操作使用 `command.key/expected/reason` 信封，与 waveform 的 `idempotency_key/expected_version` 信封分开实现。首次创建或首次结果复核使用明确 absent 前提；追加参数版本按当前参数版本链的最大版本前提提交，其余动作按各自资源/审核版本从响应读取，不能把所有 create 命名动作都发送 absent。请求结果不确定时保留原 key/body，使用现有请求查询恢复，不换 key 重新提交审批。

测试至少使用 algorithm_engineer 与独立 reviewer 会话。运行实际要求 `inversion.run` 加 `waveform.read/raw.read/export`；导出另查对应能力。管理员有全部页面/能力仍不得自审。自动化两账号行为称“软件权限流程测试”，不是人员签字。

### 7.3 来源与校准独立性

当前合同要求非空 `calibration_cycles`。同周期合成依据如实记录真实归档周期身份和绝对时间，保留 `independent_comparison=false` 及 overlap 理由；不伪造另一次独立标定。对 software_pair_test，可运行并复核软件研究记录，但 `field_accuracy_certified=false`、`not_field_validated` 不变。

将来接入实测数据需要独立标定、实际传感器和同步依据及新的适用范围审核；本有限合成合同直接拒绝 `field_pair_input`。

## 8 结果与报告状态

每个原生功率点保留原始索引、角度窗口索引、误差分项、名义中间量、物理/数值预算及拒绝原因。预算不足的点没有有效载荷，不通过剪裁载荷或补画恢复可用性。

新版报告分开记录：`assertion_status`、`expected_outcome`、`observed_outcome`、`phase/reason_code`、`approved_execution_status`。例如噪声被正确拒绝可使负例断言 passed，但该 case 的批准反演状态仍为 refused，不能计为反演正例成功。

预注册正例通过必须同时满足：

- 实际 run completed，prediction 和当前结果适用性均 applicable；
- 原始预测覆盖≥0.80、原始共同比较支撑覆盖≥0.80；
- `comparison.scope=original_valid_support`，载荷 RMSE 可计算且≤500 N；
- 正式逐点物理/数值准入检查满足本稿全部条件；
- 输入、审批、模型、运行、结果与导出摘要可追溯，参考数组未进入预测；
- 来源仍为合成软件验证，硬件和现场项仍列未执行。

queued 超时、科学依据缺失、审批失败、计算失败和预期拒绝分别记录；不把“不崩溃”“HTTP 202”“预检通过”写成算法通过。`LabHttp` 必须识别反演顶层 `code` 与 waveform 的 `error.code`，否则负例不足以证明预期错误被触发。

## 9 验证矩阵与停止条件

采用已获同意的分层验证：每个模块定向测试；数值闭环和真实服务集成这两个关键节点做独立审查；完成集成后才跑相关完整回归，不因文档更新重复长时间数据库实验。

| 层次 | 必须验证 | 不合格时 |
| --- | --- | --- |
| 原版本保护 | v1 数值文件、旧包/报告/部署摘要不变；旧结果可读 | 停止交付并查明差异 |
| 严格合同 | 缺界、负界、统计标准差冒充绝对界、错误摘要/版本/来源、未知字段、超尺寸 | 拒绝，不补默认值 |
| 运动权重 | 七种边界位置、对齐与非对齐中心、非均匀时刻、多项式重现、线性/二次残差盲点 | 不进入机械预算 |
| 时序及截断 | 独立抖动、共同偏移、采样率误差、三/四阶导数、缺口与支持边界 | 明确不可用区段 |
| 物理与数值分账 | α 影响双侧惯性、θ 影响 J/重力、ω 影响损耗/倒数；100 Nm 与因子阈值的等号/刚超界 | 保留失败与分项，无有效载荷 |
| 独立正例 | base、balance、friction、speed 使用同一固定配置，各自满足覆盖与 RMSE | 保持 blocked/failed，不删除场景 |
| 明确拒绝例 | 原噪声幅度、缺样、削顶、已知时移、不支持机构/字段、输入变更 | 核对精确 phase/code，不冒充正例通过 |
| 真实审批链 | 自审/越权/过期版本拒绝；真实 worker、完整分页、同 key 恢复、取消/超时 | 没有合格 run/result 就不计闭环 |
| 依赖竞态 | 预检后撤销、运行中权限丢失、结果后撤销、迟到 worker | 无受限结果当作当前定量输出 |
| 展示及导出 | 两图开关、有效段断线、悬停两位小数、误差分项、来源、全部点导出、旧报告读取 | 不发布新版阅读入口 |

参考独立性要同时做两个测试：纯预测接口没有参考字段；在其他预测输入保持一致时改变参考载荷/位移只改变 comparison，不改变名义预测。端到端原文摘要变化仍需建立新证据绑定，不能为这个测试绕过归档摘要检查。

初版正例限定 8 秒、128 Hz、1025 帧及明确机械族。准入权重测试覆盖额外时间形态，不等于这些形态已加入正式支持范围。四个机理正例通过后才扩展至原预注册扩展场景；任何新增范围另增版本。

停止条件明确包括：严格区间依赖不可用、证据包围仍超预算、一个必需正例未达覆盖/RMSE、单请求超过原容量/期限或历史兼容检查失败。应提交真实问题及差距，不自动改变 100 N·m、1e-5、500 N 或 0.80，也不转向新估计器绕过本稿。

## 10 容量、安全与发布范围

沿用参数/API 256 KiB、原始文件 32 MiB、解码 16 MiB、worker 输入 64 MiB、结果 16 MiB、每通道 32768 点、每次一个 pair/最多两个 capture、一个执行槽、16 个等待请求、180 秒总期限。逐点误差证据计入结果容量，不能另建无界旁路。

结果原始表采用分块存储，不把每点完整参数副本反复序列化。测量实际序列化大小与运行时长后才能宣布容量合格。证明计算的区间细分数、位长和缓存大小在实施计划中固定，并在真实 worker 180 秒总期限内验证；达不到则停止，不擅自提高期限。

新环境才安装拟用数值依赖，安装制品与版本全部纳入模型指纹；隔离实例绑定本机，不开放新的外网服务。公开报告删除账号令牌、DSN、私有日志和个人路径。原始私有诊断与公开允许清单分开。

部署仅包含新代码/新包/新 lab 及新阅读入口。先记录所有权和安装清单，再启动所属 worker。回退为禁用 v2 新运行并停用其所属 worker，保留所有结果及审计，不删除旧库或让 v2 结果冒充 v1。
