# 双功图对照与典型工况库设计

日期：2026-09-11  
交付截止：2026-09-11 15:00（Asia/Shanghai）

## 目标

在现有电功图反演链上增加载荷位移传感器功图、双曲线比较和算法评价；扩充典型工况轮廓及功图卡片；统一二维图表逐点交互；同时保证系统管理员获得所有岗位权限和页面。

## 数据链

虚拟终端的单个 `electric_card` 报文同时包含电参采样、机构参数、`profile_code` 和 `sensor_samples`。`sensor_samples` 模拟独立载荷/位移传感器的远传点集，带相位、位移和载荷；它与电参来自同一冲程工况，但包含确定性的零漂、比例误差和小幅谐波扰动。原始报文及 `dynagraphs.sample_data` 保存两类原始数据。

分析服务仍使用 `convert_electric_card` 生成反演功图；将传感器点按相位对齐后计算平均绝对载荷误差、最大误差、RMSE、面积偏差率、冲程偏差、相关系数及上下冲程 RMSE。传感器点、对齐点、比较指标、校准参数和模型版本写入 `conversion_json` 与 `model_runs.output_snapshot`，不新增外部服务。

## 典型工况

工况库覆盖：正常、游动凡尔漏失、固定凡尔漏失、双凡尔漏失、抽油杆断脱、油管漏失、供液不足、气体影响、气锁、出油管线部分堵塞、滤沙器/附件堵塞、高含水、盘根盒过紧、砂阻、活塞部分脱出工作筒、上挂、下挂、活塞被卡、衬套松动、连抽带喷。

每个细分 `profile_code` 有独立归一化轮廓与中文名称，并映射到现有稳定诊断大类。UI 同时展示“传感器工况样本”和“机器诊断”，避免把视觉样本标签伪装成已经训练完成的 20 分类模型。正常工况载荷差目标为 20–35 kN、充满度大于 0.8，形成丰满四边形；故障轮廓保持各自的低载、漏失、凹陷、冲击、卡滞或波动特征。

电功图不使用单一母线缩放。同一 `profile_code` 的上下冲程功率支路按相位、峰值、凹陷和谐波分别调制，在供液不足、阀漏失、杆断脱、砂阻、卡滞和平衡异常等情形下呈现可辨识的电功曲线；电功数据仍通过机构模型反演为对应示功轮廓，保持功率、转矩与载荷三者的数据闭环。

## 页面与交互

功图卡片顶部展示工况和报警级别，中部显示两张共坐标的曲线，底部显示井名、时间、冲程、冲次、最大/最小载荷、载荷差、面积、充满度、泵效、产液量、可信度和建议。复选框可独立开关“电功图反演”和“载荷位移传感器”曲线；图例、颜色和线型不同。

所有二维折线/功图使用统一交互协议：点元素保存序列、x/y、单位和扩展信息；渲染后由全局委托事件显示可视浮层、点高亮及横纵辅助线。电功图、滤波、示功图、趋势、遥测与恢复曲线均使用该协议；键盘聚焦点也能读取相同信息。
