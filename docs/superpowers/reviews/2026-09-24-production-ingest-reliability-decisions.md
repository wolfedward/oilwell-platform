# WP-03 实施裁决与代价记录

本记录按任务与依赖的先后列出执行日志中的全部 58 项裁决，包括最后一次独立审查未判断范围的三项处理决定、最终门禁的两项测试工具修正和受策略限制的临时目录保留。各项同时记录理由或判断错误时的代价；它不代替测试报告，不是投产批准。

## Rulings I made / 实施中作出的判断

1. 输入分类测试覆盖九类无状态错误，数据库编号冲突由事务测试覆盖；若判断有误，调整测试归属，不改变协议。
2. 基线回归期间只准备未接入的新契约模块；若基线失败，先调查再接入。
3. 第一单元回归期间准备隔离环境保护测试，不同时操作数据库；若接口变化，返工准备内容。
4. 增加独立重复观测表，保留原始事实不可变；代价是增加一表、权限检查及查询关联。
5. 唯一索引用主题和正文摘要，复用前仍核对完整字节，以容纳超长主题；代价是额外摘要和碰撞时明确拒绝。
6. 第二单元回归期间只准备未接入的仓储测试；若前置检查失败，修改准备内容。
7. 空原文按一个逻辑配额字节计费，原文仍是零字节；代价是逻辑容量比实际原文字节多出空记录数。
8. 自动重开案件采用独立迁移 002 和受限函数，不给入库身份通用修改权；代价是额外迁移、授权及安全测试。
9. 第三单元回归期间只准备接收器和配置测试；若接口不符，返工，不提前完成下一单元。
10. 新模式独立加载自身凭据，不依赖未使用的旧入库密码；代价是扩展旧配置加载器并验证兼容性。
11. 第三单元回归期间实现未接入的两个纯模块；若前置检查失败，修订模块后再接线。
12. 增加可配置的 MQTT 入站窗口及数值边界；代价是可选连接参数与更严格的新模式配置校验。
13. 修复全量回归揭露的既有测试锁顺序和 HTTP 未读请求关闭问题；代价是调整测试事务、增加最多 0.5 秒/64 KiB 的关闭排空。
14. 前述修复后以真实整树回归同时覆盖第三、四单元，不隐藏新测试；代价是任何失败都会阻止两单元完成。
15. 第三、四单元回归期间只准备发件队列测试；若前置接口变化，返工准备内容。
16. 发件队列增加可选最大重试间隔和独立工作实例编号；代价是兼容性构造参数，不改数据库和协议。
17. 复用已验证的回执调度函数，不为满足计划形式而改动；若后续补发暴露问题，再调整该函数。
18. 第五单元回归期间只准备隔离的发布器边界测试；若契约变化，返工，且不以模拟结果冒充互通证据。

27. 修复中心和网关时钟回退时错误复活过期租约的问题；代价是跨两个组件的修正及额外回归，不改协议或结构。
