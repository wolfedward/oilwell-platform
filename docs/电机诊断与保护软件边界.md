# 电机频谱证据与保护回放的软件边界

本模块只接受显式声明的采样、机器参数和研究阈值，输出可审查的软件证据。它不连接继电器、变频器或控制寄存器，不发出跳闸或复位命令，也不批准现场运行。`status=completed` 仅表示计算完成；频谱的 `support`、`finding` 和原因才说明能否解释结果。任何输出均为 `fault_confirmation=false`、`field_validation=false`、`control_eligible=false`；保护回放另有 `hardware_execution=false`。

## 电流频谱

输入是一相、等间隔、瞬时电流的原始安培值。算法先减去直流均值，记录未经加窗的交流 RMS 和八个等长子窗的 RMS 变化，再使用周期 Hann 窗及有界 radix-2 FFT。单边非直流、非奈奎斯特频点按 `2|FFT|/sum(window)` 转为峰值安培。保留完整频率轴和幅值轴，不插值、不补点、不把低质量样本替换为零。幅值仅依据用户声明的校准参考，未验证计量溯源。[NI 的 FFT 与加窗说明](https://www.ni.com/en/shop/data-acquisition/measurement-fundamentals/analog-fundamentals/understanding-ffts-and-windowing.html)解释了频点、泄漏和窗的取舍；[NI 的数字化采样说明](https://www.ni.com/en/shop/electronic-test-instrumentation/oscilloscopes/using-a-digitizer-for-time-domain-measurements.html)是抗混叠和采样前端声明的背景资料。

侧频研究仅适用于声明为工频供电的鼠笼感应电机，要求转速、极数、供电频率及其不确定度齐全、正向转差率在 `(0,0.5)`、主频足够强、两侧频都处于正频率和声明的抗混叠通带。使用相关形式 `f−=-f+np/60`、`f+=3f−np/60` 传播频率与转速区间，并将每个搜索区间按 Hann 主瓣半宽 `2fs/N` 和时钟误差扩张；扩张区间重叠或超出通带即拒绝定量旁带解释。局部噪声从两侧频各自 ±10 个频点中排除主频/侧频搜索区域后取中位数。两侧频必须同时达到显式 dBc 与噪声阈值才报告 `sideband_features_present`。

即使出现成对侧频，周期负载扰动仍可能形成混淆；未经有依据的排除会出现在 `confounders` 中。研究结果不推断断条数、断条概率或健康证书。采样质量未知、削顶、均匀采样/时钟/校准/抗混叠证据缺失、转速不稳、解析度不足或变频供电时，保留可计算的描述性频谱，但 `finding=indeterminate`。缺必填字段、数值越界、非有限数、长度不匹配则拒绝输入。[早期电机电流频谱研究](https://www.sciencedirect.com/science/article/pii/S0263224110000631)与[断条和负载振荡区分研究](https://www.sciencedirect.com/science/article/pii/S0378475419302083)是现象背景；本项目所选数值上限、阈值和保守判定规则是软件契约，不宣称为行业整定标准。

## 保护规则回放

回放要求显式配置版本、依据、声明审批人、有效期、最大帧间隔、复位安全时间和 1–16 条阈值规则。它对每帧检查 UTC 时间、单调序号、启动标识、数据质量、配置有效性及规则所需的实测量。高方向在 `>=pickup` 启动，`<=dropout` 回到安全侧；低方向相反。滞回区间维持已有 pickup。只有连续有效、未跨越最大间隔的实际经过时间可累计延时。质量异常、缺相、配置撤销/过期、时间或序号倒退、网络间断和重启切断尚未成熟的计时；已闭锁的 `would_trip` 状态以及独立的硬件跳闸抑制不会因这些问题释放。

本地复位请求必须同时满足：本帧配置和所需测量有效、硬件跳闸信号为假、所有规则连续处于 dropout 安全侧达显式 `reset_safe_ms`。远程审批、选用研究或查看结果不是复位。三相偏差指标采用 `max(abs(相值−均值))/均值`，不是负序电流或电压比；均值为零时该帧无效。软件事件仅称 `would_trip`。保护继电器的整定、隔离、采样诊断、看门狗和硬件闭锁仍是设备设计与现场验证责任；[ABB REM615 应用参考](https://library.e.abb.com/public/a491466747e31f17c1257b130056ca30/REM615ANSI_appl_259901_ENa.pdf)只用作该责任边界和功能背景，不复制其现场整定值。

`ProtectionReplay(settings).step(frame)` 是逐帧复用接口。`snapshot()` 返回带模式和配置摘要的有界 JSON 状态；同配置实例的 `restore(snapshot)` 严格校验后只恢复成熟规则闭锁、硬件抑制和已接受帧游标，清除 pickup 与复位安全计时。适配器需自行完成私有持久化的完整性、原子写入与启动时恢复；损坏或不匹配的快照必须拒绝。适配器不能把研究回放输出转成设备写命令。

软件验证使用受控正弦、成对侧频和确定性规则时间轴；这些向量不是现场电机、传感器、滤波器或保护链路的鉴定证据。
