## 登录与审查

安装目录 `private/登录账号.json` 保存独立的五岗位账号。不要把该文件放入公开仓库或通过网页公开下载。预览账号不沿用原系统密码。

先使用系统管理员浏览全部页面。右上角可切换独立岗位检查页面权限；这不会改变原系统账号。登录状态仅属于本预览入口。

在“页面确认清单”中按业务分组、年度任务、确认状态筛选页面，逐页填写“需修改”或“已确认”及意见。全部页面初始为“待确认”，没有自动通过。意见写入独立状态库；重置演练不会清空意见。内容版本变化后原意见保留，但该页重新待确认。并发修改会提示刷新，不覆盖他人意见。

## 数据和操作边界

演示运行副本通过只读一致性快照完整导入，保留历史时间、功图点值和业务关联，不重置为少量种子数据。会话、旧密码、命令签名等认证信息不在网页服务副本中。原始私有快照和逐表摘要仅保存在受限安装目录。

新增页面使用明确标记的软件测试场景。曲线、研究结果和硬件状态不能视为已采集实测数据、已验证算法或已执行保护。缺测、覆盖不足、被拒绝和未接入状态会单独显示。

编辑、复核、审批、策略制定和控制方案只保存“流程演练”记录；不改写历史快照，不连接真实控制器，不发送设备命令。新输入只保存输入，不冒充已完成算法计算。导出内容带预览来源及时间口径。

工单创建后可查看独立演练详情、提交及由另一岗位复核；策略提交后可在审批页面查看。旧表单遇到版本冲突须刷新，不覆盖其他人的修改。录波文件只在浏览器预检格式、分块及摘要，保存元信息、恢复和取消的演练状态，不上传原文或创建录波对象。

历史遥测页可选测点并导出，最多显示所选范围最后 600 点；质量无效点不连线，超过中位采样间隔 1.5 倍的区间断线。原始数值仍留在表格中。产液计量页读取历史功图估算及输入因子，并列展示同日日报；采样外推日率不能直接当作全日量的精度验证。新增双图误差由所绘点计算，不代表算法经过现场验证。

## 启动与停止

使用现有 Python 解释器，在安装的 `code` 目录运行：

```powershell
& 'C:/Users/hp/Documents/外专双百/.venv/Scripts/python.exe' -B -m tools.page_preview launch --target 'C:/Users/hp/AppData/Local/OilWell/page-preview-20261012'
& 'C:/Users/hp/Documents/外专双百/.venv/Scripts/python.exe' -B -m tools.page_preview status --target 'C:/Users/hp/AppData/Local/OilWell/page-preview-20261012'
& 'C:/Users/hp/Documents/外专双百/.venv/Scripts/python.exe' -B -m tools.page_preview stop --target 'C:/Users/hp/AppData/Local/OilWell/page-preview-20261012'
```

只绑定本机回环地址；端口被其他程序占用时拒绝启动，不结束陌生进程。停止前校验实例身份。启动失败的详情保存在 `private/server.log`。本版不设置开机自启，不依赖外网资源。

`installation.json` 记录固定代码提交、文件摘要和数据快照标识；`business.manifest.json` 为逐表对账清单。`private/verification.json` 与 `private/screens` 保存实际安装检查和两种屏幕尺寸的截图。不得在安装目录临时编辑代码；修改需回工作树测试并重新发布固定版本。

固定版本更新通过 `repackage --target <安装目录> --revision <已测试提交>` 完成，须先停止所属预览实例；保留旧代码目录、旧安装清单、业务快照、账号和页面意见，不重新生成历史数据。实际代码目录以 `installation.json` 中的 `code_path` 为准。
