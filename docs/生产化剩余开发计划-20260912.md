## 1. 结论

当前版本已经具备完整的单机演示业务链、可追溯数据库、权限审计、虚拟终端、功图分析、节能策略、审批、指令和工单，适合作为需求确认与算法联调基线；但它仍是单机 SQLite + 虚拟终端架构，不能直接定义为经过生产验证的油田控制系统。

按任务书三年度产品范围，要达到可部署、可联调、可试运行并具备安全控制边界的生产候选版本，建议安排 **28 个日历周**。该估算以 4—5 人并行团队为基准：平台后端/数据工程、前端、算法、嵌入式/边缘网关、测试与现场工程；若由单人串行完成，预计 48—60 周。没有现场硬件和成对实测数据时，可在前 16 周完成实验室生产候选版，但不能对功图反演精度、电机故障识别率和真实启停安全性作生产结论。

## 4. 技术路线依据

- 有杆泵结构、抽油机、泵和杆柱的工程参数应建立在 API SC11 维护的 Spec 11E、Spec 11AX、TR 11L、Bull 11L2 等体系上，而不是仅按图片轮廓拟合。[API SC11](https://mycommittees.api.org/myc-standards-ecs-sc11)
- 电参软测示功图采用三相瞬时量、对称分量/正序功率、驱动与四连杆运动学、扭矩因数及光杆载荷关联模型；死点附近必须单独处理和标定。[软测示功图研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10975837/)、[电功率构建示功图论文](https://doi.org/10.1109/ICPCI.2012.6486365)
- 泵功图和井下诊断需要杆柱参数及波动方程/有限元模型，不能把地面示功图直接等同于泵功图。[有限元井下功图研究](https://doi.org/10.1016/j.upstre.2022.100078)
- 断条诊断以电机电流特征分析为主线，跟踪基频两侧与滑差相关的边带，同时必须控制负载变化、噪声和其它故障造成的误判。[IEEE MCSA 工业案例](https://doi.org/10.1109/2943.930988)、[IEEE 多特征断条检测](https://ieeexplore.ieee.org/document/1432846/)
- 设备上行采用具备命名空间、载荷和会话状态约定的 MQTT Sparkplug，而不是自定义裸 TCP 直接进入中心业务。[Eclipse Sparkplug 3.0](https://sparkplug.eclipse.org/specification/)
- OT 安全按分区分域、最小权限、远程访问控制、补丁/备份/恢复和安全监测设计，参考 IEC 62443 与 NIST SP 800-82 Rev.3。[IEC 62443-3-3](https://webstore.iec.ch/en/iec_catalog/product/preview/?id=L3B1Yi9wZGYvcHJldmlldy9pbmZvX2llYzYyNDQzLTMtM3tlZDEuMH1iLnBkZg%3D%3D)、[NIST SP 800-82 Rev.3](https://csrc.nist.gov/pubs/sp/800/82/r3/final)

## 5. 必须获得或最终确认的现场输入

1. 计划采用的 MCU/DSP 型号、ADC 位数/采样率、三相电压电流互感器、位移/载荷传感器、存储和通信模块。
2. 抽油机型号与四连杆尺寸、平衡块、减速比、电机铭牌/VFD 参数、杆柱组合、泵径、泵深、井斜与液性参数。
3. 至少一批同周期成对数据：三相原始波形、曲柄角/位移、载荷传感器示功图、人工确认工况、计量产液。
4. 现场网络和协议：RS-485/Modbus、工业以太网、4G/5G/APN、VPN、中心 MQTT/SCADA 接口。
5. 控制权限：平台只给建议、审批后远控，还是允许安全条件下自动启停；所有硬联锁和紧急停机责任边界。
6. 首期井数、采样频率、数据保留年限、可接受停机时间和部署形态。

在这些材料缺失期间，默认采用“硬件抽象层 + 协议仿真器 + 影子控制”继续开发；任何基于仿真或公开数据得到的指标都标记为实验室结果，不冒充现场生产结论。

## 6. 首个两周冲刺

- 建立生产版架构决策记录、设备点表和数据契约。
- 将当前单体代码切出领域模块边界，建立兼容旧演示数据库的迁移通道。
- 建立 PostgreSQL/时序库开发环境、结构化日志、指标和健康探针。
- 定义边缘网关插件接口，先实现 Modbus 仿真适配器和离线消息队列。
- 建立成对电参—传感器功图数据导入、质量校验和数据集版本表。
- 建立生产门禁流水线：单元、契约、迁移、性能、安全和浏览器端到端测试。

两周结束时交付 M1 评审包；若现场硬件仍未确定，不阻塞平台底座与数据契约，但硬件相关参数保持“待现场确认”，不写死在算法中。
