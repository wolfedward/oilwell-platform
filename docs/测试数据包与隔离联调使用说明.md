# 可复现测试包与隔离联调

本工具用于核验平台的软件计算、数据协议和审计链路。所有输入均为**软件生成的合成数据**，不是现场测量，也不是脱敏生产数据。原演示版、8765/8770/8772/8774 既有安装保持独立，不作为本工具的测试目标。

## 本次可交付与未完成项

已实现：确定性数据包、严格文件校验、独立正向模型、实际 Modbus TCP → MQTT → 数据库存储 → HTTP 查询、重发/冲突/权限/恢复检查、波形证据绑定及七类研究的实际计算与依赖撤销验证。是否通过，以具体运行报告为准；模板存在、离线检查或 MQTT PUBACK 都不等于数据库已入库。

当前固定反演误差预算未通过：速度变化样本的速度误差超过固定预算；声明域内的功率/速度组合还存在转矩误差超过 100 N·m 的反例。因此参数不提交批准、不伪造第二条“已反演”曲线，报告保留 `blocked`。不能把局部数值对比当作整个声明域或现场精度的证明。

未完成：硬件样机、现场标定、物理保护输出、现场故障确诊及节能效果验证。在线波形分片/ACK、Broker 断电持久化也不在本次已执行链路内。软件账号复核不是人员签名。B 包硬件工程设计及 C 包全页面真实接入不由本数据包替代。

## 数据规模

| 内容 | smoke 联调子集 | extended 离线扩展 |
| --- | ---: | ---: |
| 功图周期 | 8 | 48 |
| 仅供显示的典型轮廓 | 0 | 12 |
| 三相电流场景 | 4 | 8 |
| 历史井数 | 2 | 8 |
| 15 分钟历史帧 | 16 | 10,752 |
| 历史积分日记录 | 2 个不完整日 | 112 个完整日 |

历史产液和耗电由同一运行占空比、充满程度和能量模型生成，含波动。日积分按上海时区划分，缺测不补零、不把部分覆盖外推成全天。实际网络联调仅传已登记的 smoke 子集：基准 16 批次、192 测点；恢复检查另传 2 批次、24 测点。报告分别列出生成量和实收量。

每个包包含 manifest、配置、源码指纹、原始波形、原码缩放定义、JSONL/CSV、研究输入及文件摘要。包为只写一次；已绑定的运行证据存放于另一运行目录，不回写原包。

## 运行环境

使用本项目 Python 3.13 环境及固定依赖；生成器需要可读 Git 提交。隔离安装还需要本机 PostgreSQL、Mosquitto 和已安装的 Chrome/Edge 或 Playwright Chromium。浏览器自动检查使用独立临时配置，不读取个人浏览器资料。

默认独立端口如下，全部绑定 `127.0.0.1`。如果被占用，先检查拥有者，不要停止无关进程。

| 实例 | HTTP | PostgreSQL | MQTT |
| --- | ---: | ---: | ---: |
| monitoring | 18774 | 56432 | 19884 |
| review | 18770 | 56433 | 19885 |

软件 Modbus TCP 设备使用 15020，仅在采集验证时运行。支持 FC03/04，只读；拒绝 FC06/16。查看器可另用 18880，不代理登录、数据写入或控制接口。

## 命令

以下命令从已提交的开发工作树运行。示例绝对目录必须未存在；重复运行请换新目录。不得把业务库、旧演示目录或项目根目录作为新安装目标。`python` 可替换为本机项目虚拟环境的解释器绝对路径。

```powershell
python -m tools.testpack generate --config C:/path/to/repo/config/testpack/smoke.json --output C:/OilWell/testpack-smoke-new
python -m tools.testpack validate --pack C:/OilWell/testpack-smoke-new --report C:/OilWell/smoke-offline-new.json
python -m tools.testpack generate --config C:/path/to/repo/config/testpack/extended.json --output C:/OilWell/testpack-extended-new
python -m tools.testpack validate --pack C:/OilWell/testpack-extended-new --report C:/OilWell/extended-offline-new.json
python -m tools.testpack lab-init --pack C:/OilWell/testpack-smoke-new --root C:/OilWell/lab-new --source C:/path/to/repo
python -m tools.testpack lab-run --pack C:/OilWell/testpack-smoke-new --root C:/OilWell/lab-new --run C:/OilWell/lab-new/run-001 --stage all
python -m tools.testpack view --pack C:/OilWell/testpack-smoke-new --report C:/OilWell/lab-new/run-001/public/report.json --port 18880
```

`lab-run --stage all` 依次执行离线、网络采集、波形证据、来源撤销、七类研究和真实浏览器检查。运行目录保存每阶段检查点、原始回执、输入/结果摘要、封存部署提交、起止时间及截图。单独运行也可选择 `telemetry`、`waveforms` 或 `studies`，但不能把零散阶段拼成全部通过。采集身份已经登记时，不应在同一实例重复整套注册流程，应新建实验实例。

总状态包含 `passed / failed / blocked / incomplete`；每项另有 `not_run`。存在未通过、阻断或未运行时，命令退出码为 1，不应修改报告把它变为成功。当前固定反演预算阻断意味着完整交付报告预期不是 `passed`。

原始运行记录含内部标识与路径，应保留在私有目录。对外导出使用字段允许清单，并重新核对公开检查与原始证据一致性：

```powershell
python -m tools.testpack report --run C:/OilWell/lab-new/run-001 --output C:/OilWell/public-report-new
python -m tools.testpack lab-stop --root C:/OilWell/lab-new
```

`lab-stop` 只停止所有权标记、进程身份和数据库实例标识均匹配的本轮子实例，不删除数据。查看器是独立进程，前台运行时用 Ctrl+C 关闭。

## 阅读报告

- `offline`：文件、协议、数据规模及摘要校验。
- `numeric`：纯算法/机理核验；未批准反演明确阻断。
- `software_network`：真实软件网络、入库回执、历史查询与恢复检查。
- `http`：真实研究、波形证据和审计接口；包含预期拒绝的负例。
- `browser`：在真实生成包及对应报告上执行的浏览器交互检查。
- `hardware`：未运行，不能用以上软件结果替代。

曲线默认不显示大圆点；悬停或方向键显示原始坐标，两位小数仅影响展示。坏质量/缺测保持断开。只有具备真实批准结果时才可显示反演预测；轮廓库只供显示，不计算反演精度。公开报告展示实际研究状态、依赖是否仍有效、记录编号和摘要，不公开口令、连接串、个人路径或原始私有日志。
