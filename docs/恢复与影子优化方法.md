# 液面恢复、有限候选影子调度与效果描述

本模块只提供离线软件研究结果。每份输出都标注 `shadow_only=true`、`dispatch_allowed=false`、`field_validation=false`。它不下发启停命令，不代替井场联锁、设备保护、工艺审查或实测验证。输入的面积、流量、电输入功率和液面深度必须由提交者说明来源；软件没有独立核验这些声明参数。

## 液面深度恢复

测量坐标为从给定基准面向下的深度（m），关井时刻为 `t=0`，仅接受关井且质量为 `valid` 的观测。使用经验式

`d(t) = d_eq + A exp(-t / tau)`，其中 `A > 0`、`d_eq >= 0`、`tau > 0`，时间单位为 min。

用户必须显式给出 tau 搜索范围、网格密度和拟合筛选值。程序在该范围的对数网格上，对每个 tau 解析求解 `d_eq` 与 `A` 的两参数最小二乘，依 `(残差平方和, tau)` 选最优。非物理参数、边界最优、有效点不足、时间缺口、变化幅度过小、R² 或 RMSE 不合格都导致 `rejected`，不会把负值截成零或伪造拟合参数。无效质量点连同原因保留；剔除后不能跨越允许的最大观测缺口。

逐个删除一个有效观测后重拟合，报告 tau 与平衡深度的变化范围。最多五个联合参数情景取自主拟合和真实的留一拟合极值，绝不把不同拟合的参数极值任意拼接。该范围是**敏感性检查，不是统计置信区间**。深度残差包络是实测最大绝对残差加已知测量精度；精度未知时另行标记，不解释成零测量误差。拟合的时间及深度支持范围仅取原有效观测，不给范围外动态预测背书。

## 有限时域影子调度

审查服务只向计算函数注入已经批准、状态为 `fitted` 的恢复结果；公开输入只能引用 `recovery_record_id`。每口井提交一至八个完整候选，最多四口井，时域为上海当地午夜起止的完整一至七日。算法预计算各井候选，再枚举全部笛卡尔积；`search_complete=true` 只表示**已穷举提交的有限候选集合**，不是连续时间或所有启停策略的全局最优。

设储液面积 `A_s`（m²）、泵液量 `q`（m³/min）、开机指示 `u`，每一状态段的解析物料平衡为：

`d_next = d_eq + (d - d_eq) exp(-Δ/tau) + u q tau / A_s · (1 - exp(-Δ/tau))`。

每个真实拟合情景都检查段端点的原观测深度范围、沉没度、连续停机支持时长和终点深度。该一阶常输入微分式在单段内单调趋向其平衡值，因此端点覆盖该段的深度极值。最短开停时间计入时域前的已持续时长，最后一段仍须满足最短持续时间。真实 `off→on` 启动按上海日历日计数；初态已开机且启动时间未完时延续启动功率，但不新增启动次数。

功率和能量按状态边界、启动结束及当地午夜精确切分：停机用待机输入 kW，启动时段用启动输入 kW，其余开机用运行输入 kW，乘实际小时得到 kWh。组合在所有功率边界检查瞬时总功率及同时启动数，并逐井逐日检查最低产液和最高启动次数。候选按总电量、峰值、启动次数和 ID 排序。不可行时保留完整的拒绝类别计数和最多十个拒绝示例；没有“近似可行”替代方案。搜索预算超限会明确报错，不暗中丢弃候选。

## 观测效果

基线与处理阶段只累计质量为 `valid` 的真实观测区间，报告各阶段有效观测小时、覆盖率、液量、能量和每有效观测小时的描述性差值。无覆盖时比率是 `null`；覆盖不足或可比性声明不完整时为 `insufficient_evidence`。时段缺口不补算，因此 `actual_energy_saving_kwh=null` 且 `causal_effect_proven=false`，即使描述性差值为负也是如此。要判断实际节能和因果作用，仍需独立设计现场对照、同口径电输入计量及工况核查。

## 参考依据与实现边界

- [NIST 非线性最小二乘回归](https://www.itl.nist.gov/div898/handbook/pmd/section1/pmd142.htm) 说明指数形式可用最小二乘估计，也指出异常值敏感性。本实现采用有界 tau 网格与留一敏感性，未据此构造置信区间。
- [A New Intermittent Pumping Design for Fluid Shortage Wells](https://www.nature.com/articles/s41598-020-59094-0) 讨论间歇抽汲、井筒液面及沉没度变化，为研究背景；本文的一阶储液方程与软件筛选值是本项目的明确简化，并非该论文验证了本实现。
- [Scheduling pumpoff operations in onshore oilfields with electric-power constraints and variable cycle time](https://www.sciencedirect.com/science/article/abs/pii/S0305054817302435) 研究电力约束下的井群调度。本模块只穷举用户提供的小型有限候选，不采用论文的混合整数模型，也不引用其性能结论。
- [Echometer 声学液面测量资料](https://www.echometer.com/technical-papers) 提供现场测量背景；提交者仍须记录仪器、基准、精度、质量及操作状态。具体测量误差和现场适用性不能由本软件推定。
