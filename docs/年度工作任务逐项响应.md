### 软件验证口径

新增针对性测试覆盖严格输入、源资料隔离、数值极限、真实计算、权限与幂等、复核版本/撤销、持久化和可下载资料。`tests/test_review_release.py` 使用实际 HTTP 服务和七个实际计算引擎，验证创建→双用户复核→影子选用→依赖计算→导出→上游撤销→限制下游，并在新服务实例中重新读取相同结果摘要。`tools/verify_review_release.py` 仅在显式确认的本机 review 模式中创建带 `software_fixture` 来源的验证记录，不修改演示库或上传为实测。

独立审查发现的极小数值约束、撤销后选用、设备重启序号归零、安装源码字节一致性和服务就绪问题逐项修复验证。各阶段测试不相加作为全项目完成率；最终部署、来源固定的组合回归和备份恢复以交付记录为准。[本机审查部署](本机审查部署.md) 载明独立目录、账号领取、停止和恢复到新目标的操作方法。
