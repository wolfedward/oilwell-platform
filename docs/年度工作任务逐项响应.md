## 5. 持续实施顺序

1. **WP-01：中心入口与公开接口校验一致（Y1-02 / Y1-03）**。在既有采集路径内修正解析边界，不改变主题/schema，不增加现场控制；状态见下节。
2. **WP-02：设备身份、井号时效绑定与点表版本（Y1-02 / Y1-03 / Y3-05）**。这是后续采集、算法和策略共享同一来源的基础；不得从演示台账批量激活真实设备。
3. **WP-03：异常报文持久隔离与应用回执（Y1-02 / Y1-03）**。先持久保存再确认，数据库不可用不确认；严格拒绝本身不能解决永久错误消息反复投递。
4. **WP-04：同步波形和成对功图数据集（Y1-01 / Y2-02 / Y3-04）**。时间、周期、校准和缺失信息先行，支持厂家测试向量，不伪造现场来源。
5. **WP-05：功图反演/工况模型治理及决策（Y1-01 / Y1-04 / Y3-06）**。参数辨识、独立验证、规则与机器学习/BP 基线比较、人工复核与回滚。
6. **WP-06：恢复试验与影子节能优化（Y2-01 / Y3-02）**。用可信观测评价制度，不将模拟节电率当实测成果。
7. **WP-07：电机保护、频谱与断条诊断（Y3-01 / Y3-03 / Y3-04）**。先录波质量和离线诊断，再实验台保护整定与硬件联调。
8. **WP-08：整机及三模块集成验证（Y2-02 / Y3-02 / Y3-05 / Y3-06）**。部署、耐久、备份恢复、现场影子验证，最后在明确安全条件下讨论控制放权。

上述为依赖顺序，不是对原任务年度时间作修改，也不等于所有项已经实现。硬件与真实数据缺失不阻塞软件协议工作，但阻塞对应实物、安全与效果结论。
