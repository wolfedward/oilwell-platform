# 后续接口设计草案（当前不开放）

日期：2026-09-23。此文件是研发边界，不是现有服务能力声明。以下主题、字段和状态须经接口评审、实现、测试后再冻结；厂家目前只实现 INTERFACE.md 的 v1 遥测。

## 1. 设备身份与注册

推荐独立 PostgreSQL 设备注册表，网关/终端复合标识、厂家、型号、硬件/固件版本、证书指纹和采集能力。候选状态为 pending/active/suspended/retired。初始 pending 不进入生产数据视图。经运维审核、井号绑定和点表版本确认后 active；禁止从模拟台账自动复制为 active。

井号绑定保留生效时间与版本，旧补传数据按原采样时间所属绑定解释；不得因设备迁井而重写历史井号。身份可信性由 Broker 认证与 ACL、注册状态和安装记录共同建立，不能只相信报文中的 gateway_id。

## 2. 配置与回执

候选下行域为 `oilfield/v2/{gateway}/{device}/config`，候选回执域为 `.../config-ack`。配置含 config_id、point_map_version、内容摘要、有效期、签发者、目标身份和只读采集点表。终端经历 received → validated → applied 或 rejected；平台不得把“已发送”显示成“已应用”。

发布必须签名校验、版本比较、原子切换和可回退；重复 config_id 不重复应用，过期配置拒绝。v1 中心不会消费上述主题，也不会远程修改当前网关文件。密钥轮换和 OTA 使用独立权限，不能借此开放启停。

## 3. 同步波形与成对功图

候选波形域为 `oilfield/v2/{gateway}/{device}/waveform`，独立 schema，不修改已冻结 v1 标量含义。每个采集批次至少描述 capture_id、cycle_id、测量来源、校准版本、点表版本、采样频率、UTC 起点、单调采样计数、时钟不确定度、各通道单位/比例、编码、总样本数、chunk_index/chunk_count、内容摘要和缺失掩码。

电参、载荷、位移同周期配对；传感器实测与算法反演必须不同来源。缺片、超时、摘要不符、失准或时间基准不明时，不进入模型标定和自动策略。设计应支持有界分片与本地文件续传，不能用 MQTT 一条超大消息代替文件协议。

## 4. 应用入库回执与异常隔离

候选回执域为 `oilfield/v2/{gateway}/{device}/ingest-ack`，绑定 message_id、原始摘要和处理结果；设备在应用确认前保留可恢复副本。Broker PUBACK 与此回执含义不同。

畸形、冲突、未注册和点表不匹配报文进入受限持久隔离区；先记录原始字节/摘要、接收时间和拒绝原因，再确认 MQTT 消息，避免毒消息反复占住消费入口。数据库不可用仍不得确认。配置恢复后重放需单独授权、幂等和审计。

## 5. 控制边界

远程启停主题、Modbus 写功能、自动控制接口暂不开放。必须先完成实物联锁、风险评估、权限与审批、命令幂等/有效期、执行回读和安全停机测试，再发布独立控制协议。网络失效不能替代本地保护责任；软件样机不代表现场可控。

## 6. 实施顺序

设备登记与有时效的井号绑定 → 点表版本 → 准入与持久隔离 → 应用回执 → 波形/双功图数据集 → 硬件在环与现场验证 → 经批准的控制协议。每一步单独提供实现状态与测试证据，未实现功能不出现在“可用接口”目录中。
