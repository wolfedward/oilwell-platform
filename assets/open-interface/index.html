MANUFACTURER ONBOARDING

厂家如何开始联调

  1. 提交设备与点表

    提供型号、版本、单位、字节序、量程和标定说明；现阶段由运维分配身份与 ACL，不自动注册。

  2. 选一种接入方式

    标准 Modbus 终端经平台网关接入，或自主实现 MQTT v1。两种方式遵循相同数据约定。

  3. 离线校验报文

    下载示例与校验器。校验器只检查报文，不联网、不取凭据、不发送控制指令。

  4. 隔离环境联调与准入

    检查断网补传、重复报文、错身份、时钟漂移和缓存满；另行完成电气、采样与安全验证。

python validate_telemetry.py --topic oilfield/v1/GW-EXAMPLE/D-EXAMPLE/telemetry --file telemetry-example.json

校验器使用 Python 3.10+ 标准库，退出码 0 表示协议预检通过，2 表示不通过。示例是公开测试向量，不是现场测量。

可选应用回执：核对原始报文

python validate_ingest_ack.py --topic oilfield/v2/GW-EXAMPLE/D-EXAMPLE/ingest-ack --file ingest-ack-example.json --telemetry-topic oilfield/v1/GW-EXAMPLE/D-EXAMPLE/telemetry --telemetry-file telemetry-example.json

stored 只证明中心保存，不证明质量良好或已被业务使用；quarantined 不计正常测点。无法安全关联的原文没有应用回执，须保留并告警。中心“已交 Broker”不是“网关已确认”。

BOUNDARIES

版本、安全与真实性

  • 本包允许厂家复制和修改原创参考材料；第三方芯片图纸、标准文本和商标不在本许可中。
  • 当前标量协议不是同步功图协议，不是 Sparkplug，不是远程控制协议。
  • MQTT PUBACK 不等于中心业务入库回执；Broker 持久状态丢失或会话过期仍有数据风险。
  • 时间同步、传感器标定与物理安装必须验证，不能靠报文格式正确推断采样准确。
  • 当前平台文档在本机开放；没有自动发布到互联网，没有公开任何现场地址和实际凭据。
